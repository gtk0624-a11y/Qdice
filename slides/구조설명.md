## 1. 전체 파일 구조

```
slides/
├─ index.html              ← 서랍(슬라이드 목록·새로 만들기·복사·삭제)
├─ 구조설명.md              ← 이 문서
├─ decks/
│   ├─ index.json          ← 내장 슬라이드 목록 (새 내장 슬라이드를 넣으면 여기에 한 줄 추가)
│   └─ unification-30-32/
│       ├─ deck.json       ← 통일 단원 슬라이드 내용(31장)
│       └─ media/*.webp    ← 슬라이드에 들어간 그림
└─ v1/                     ← 엔진 1판 (새 기능은 v2 폴더로 새로 만듭니다. v1은 건드리지 않습니다)
    ├─ engine.js           ← 공통 부품(저장·그리기·QR·유튜브·템플릿)
    ├─ engine.css          ← 모양(라벤더 파스텔)
    ├─ play.html / play.js ← 교사 화면(발표 + 편집 + 수업 방 관리)
    ├─ join.html / join.js ← 학생 화면(QR로 들어오는 곳)
    ├─ lib/qrcode.js       ← QR 만드는 라이브러리(MIT)
    └─ ggumsong.png        ← 꿈송이 그림
```

## 2. 교사·학생 데이터 흐름

- 저장소: Firebase 실시간 DB(nation-game-cf684, 딜시·국가 만들기와 같은 곳). 연결이 안 되거나 주소 끝에 `?demo=1`을 붙이면 "체험 모드"(내 브라우저에만 저장, 학생 연동 안 됨)로 동작합니다.
- 슬라이드 내용: 내장은 `decks/…/deck.json`(읽기 전용). "다른 이름으로 저장"하면 `rooms/SLDECK/<공간>/<id>`에 복사본이 생깁니다.
- 수업 방: 교사가 `🚀 수업 시작` → 4자리 방 코드 생성(`rooms/SLROOM/<코드>`).
  - `state`: 교사가 지금 보는 장면·공개 단계 → 학생 화면이 따라옴
  - `users/<uid>`: 학생 닉네임·번호·모둠
  - `live/<장면>/<요소>`: 질문 월 글(items), 투표(votes), 모둠 학습지(ws/g모둠/f·s)
  - `rx`: 이모지 반응, `und`: 이해도 신호(알겠어요/반쯤/모르겠어요)
- 학생 글은 교사가 "공개"를 눌러야 큰 화면에 나옵니다(승인제).

## 3. 자주 고칠 곳

| 하고 싶은 일 | 위치 |
|---|---|
| 교사 비밀번호 바꾸기 | `v1/engine.js` 위쪽 `SL.PIN = '0624'` |
| 슬라이드 내용·위젯 수정 | 화면에서 ✏️편집(코드 수정 불필요) |
| 색·글꼴 | `v1/engine.css` 맨 위 변수(`--acc`, `--bg` …) |
| 새 서식(템플릿) 추가 | `v1/engine.js`의 `SL.tpl` |
| 내장 슬라이드 추가 | `decks/<새이름>/deck.json` + `decks/index.json`에 한 줄 |
| 학생 글자 수 제한(140자)·1인 3개 | `v1/join.js`의 월 입력 부분 |
| 다른 교사용 공간 | 주소 뒤에 `?space=이름` |

## 4. 개인정보·오류 위험 지점

- 학생은 닉네임·번호·모둠만 입력합니다(실명 요구 없음). 학생에게 실명을 쓰지 않도록 안내해 주세요.
- 교사 비밀번호(0624)는 `engine.js`에 그대로 보이는 간단한 잠금입니다. 학생이 개발자도구를 쓰면 알 수 있으니 "실수 방지용"입니다. 보안 용도는 아닙니다.
- Firebase 규칙이 닫혀 있으면 저장이 거부됩니다(다른 앱과 같은 규칙이면 정상).
- 수업이 끝나면 `기록 지우기`로 학생 글·투표·학습지를 삭제할 수 있습니다.
- 유튜브가 퍼가기를 막은 영상은 슬라이드 안에서 재생되지 않고 "유튜브에서 열기" 링크로 대체됩니다.
- v1에서 아직 없는 것: 테마 전환, 화면 안 PPT/PDF 가져오기(통일 PPT는 미리 변환해 넣음), PDF 내보내기.
