# 도디쌤의 돈워리 비해피 — 구조 설명

## 파일 구조
- `index.html` : 실제판 (이 기기·브라우저 localStorage `dwb_v1`에 저장)
- `demo/index.html` : 체험판 (예시 데이터, 저장 안 함). 두 파일은 같은 코드이고 `const DEMO` 값만 다릅니다.
- 외부 의존: 글꼴(Google Fonts), 엑셀 처리(SheetJS, jsDelivr CDN) — 인터넷이 없으면 엑셀 읽기·내려받기만 안 됩니다.

## 데이터 흐름
- 사용자 입력(폼·파일·붙여넣기) → `S`(상태: items·events·owner·year) → `save()` → localStorage → `render()` 로 화면 다시 그림
- 계획서 읽기: 파일/붙여넣기 → `parseFile`/`parseText` → 미리보기(`ui.draft`, 고칠 수 있음) → 체크한 것만 `S.items`에 추가
- 예산요구서: 작년 자료 또는 현재 장부 → `ui.req`(저장 안 되는 작업용) → 출력/엑셀
- 서버·로그인 없음. 다른 사람과 데이터가 섞이지 않습니다(각자 자기 기기에 저장).

## 자주 고칠 곳 (app 파일 안 위치)
- 색·모양: 맨 위 `:root{--mint ...}` 변수
- 탭 이름·순서: `const TABS`
- 계획서 읽는 규칙(금액·기한 인식): `findAmount`, `findDate`, `parseRows`
- 체험판 예시 데이터: `sample()`
- 출력(인쇄) 모양: `@media print` 부분

## 개인정보·오류 위험 지점
- 학생 개인정보는 다루지 않는 설계입니다. 예산·행사 자료만 저장합니다.
- 저장 위치가 브라우저라서 **브라우저 기록 삭제·기기 변경 시 자료가 사라집니다** → 설정의 백업(.json) 필요.
- 한글(hwp)·PDF는 직접 읽지 못합니다(복사해서 붙여넣기).
- 카카오톡 인앱 브라우저에서는 파일 내려받기가 막힐 수 있습니다(크롬으로 열기 / 백업 글 복사).
- 금액·기한 자동 인식은 추정이므로 미리보기에서 반드시 확인 후 추가하세요.
- 예산요구서는 초안입니다. 에듀파인 제출 양식에 맞춰 옮겨 써야 합니다.
