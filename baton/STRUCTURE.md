# 도디쌤의 바통터치 구조 설명서

© 김정환 · M.A.D.T (Moral And Digital Teacher)

## 1. 한눈에 보기
서버가 없는 **단일 HTML(index.html 한 장)** 앱입니다. 깃허브 페이지에 올리면 바로 돌아가고, 선생님들은 주소만 열면 가입·설치 없이 씁니다.
인수인계서를 한꺼번에 쓰지 않고, **일하면서 "업무 카드"를 쌓아 두었다가** 인계할 때 코드·파일·인쇄로 내보내는 방식입니다.

## 2. 파일 구조
```
baton/index.html     화면·디자인·동작이 모두 한 파일에 있음
baton/STRUCTURE.md   이 문서
```
index.html 안의 순서: `<style>`(디자인) → `<body>`(껍데기) → `<script>`(동작).

## 3. 데이터 흐름 (인계자 → 인수자)
- 저장 위치는 브라우저 `localStorage`의 `dodi.baton.v1` 하나입니다(기기·브라우저마다 따로).
  - `profile`(이름·업무·학교·이미지) / `cards`(내 업무 카드) / `inbox`(받은 인계서) / `lastBackup`
- 업무 카드 한 장: 업무명, 한 줄, 시기(월), 마감일, 목적, 절차, 서식 위치, 예산, 물어볼 사람, **함정**, 연도별 메모(memos), 받은 질문(qa)
- 주고받는 것은 모두 **코드(`BATON1.…~`)나 `.baton.json` 파일**입니다. 종류는 네 가지입니다.
  | 종류(t) | 보내는 사람 → 받는 사람 | 받으면 일어나는 일 |
  |---|---|---|
  | `baton` | 인계자 → 인수자 | [받은 인계]에 인수인계서가 생김 |
  | `q` | 인수자 → 인계자 | 해당 카드에 질문이 붙음 |
  | `a` | 인계자 → 인수자 | 질문 밑에 답변이 붙음 |
  | `backup` | 나 → 나 | 전체 복원(덮어쓰기, 확인창 있음) |
- 인수자는 [내 업무로 가져와 이어쓰기]로 카드를 복사하고(같은 id는 건너뜀), 올해 메모를 덧붙여 다음 사람에게 다시 내보냅니다. 메모는 학년도별 층으로 쌓입니다.
- 서버·로그인·파이어베이스를 쓰지 않으므로 **다른 선생님의 자료가 내 화면에 보일 수 없습니다.**

## 4. 자주 고칠 곳
| 하고 싶은 일 | 위치 (index.html 안) |
|---|---|
| 앱 이름·문구·저작권·워터마크 글자 | `<script>` 맨 위 `APP` |
| 도디쌤 기본 이미지(바통 든 모습) | `DODI_IMG(기본 아바타, dodi.jpg base64)·DODI_SVG(예비)` (설정 화면에서 사진으로 바꾸는 기능도 있음) |
| 바통 넘기는 그림(빈 화면·인계하기) | `HERO_SVG`, 움직임은 `.hero .bt` 애니메이션 |
| 색·글꼴 | `<style>` 맨 위 `:root` |
| 학년도 달 순서(3월~2월) | `MONTHS` |
| 빈칸 점검 항목 | `checks()` |
| 예시 카드 5개 | `sampleCards()` |
| 카드 입력 칸 추가 | `newCard()` + `editor()` + `saveCardFromSheet()` + `cardHTML()` + `buildPrint()` 다섯 곳 |
| 인쇄 모양 | `<style>` 아래쪽 `@media print` 와 `buildPrint()` |

## 5. 개인정보·오류 위험 지점
- **학생 개인정보 금지**: 업무 방법만 적는 도구입니다. 설정 화면과 사용 안내에 경고 문구가 있습니다.
- **브라우저 데이터 삭제 = 내용 삭제**: 백업 알림(30일·1~2월)이 있고, 백업 코드·파일로 복원합니다.
- **카카오톡 인앱 브라우저**는 저장 공간이 크롬과 따로입니다. 상단에 "크롬에서 열기" 안내 배너가 뜹니다(`openKakao`).
- **코드가 길면** 카톡 메시지가 잘릴 수 있어 9,000자 넘으면 안내가 뜹니다. 이때는 파일 저장을 쓰세요.
- 일부 환경(미리보기 등)은 파일 저장·인쇄·자동 복사를 막습니다. 코드 상자의 수동 복사가 항상 대안입니다.
- 코드 끝의 `~`는 코드의 끝을 알리는 표시입니다. 지우면 읽는 데 실패할 수 있습니다.
- 모든 사용자 입력은 `esc()`로 이스케이프해 화면에 넣습니다(새 화면을 만들 때도 지킬 것).
