# 도디쌤 서랍 — 구조 설명서

작업표시줄 아이콘 한 번 → 작은 창에서 내 프로그램·사이트 목록 → 클릭하면 새 탭으로 열림.
(설치형 웹앱 = PWA 방식. 서버·가입·비용 없이 깃허브 페이지만으로 동작)

---

## 1. 전체 파일 구조

| 파일 | 역할 | 고치는 빈도 |
|---|---|---|
| `index.html` | 서랍 화면과 모든 동작(검색·탭·즐겨찾기·추가·설정) | 거의 안 고침 |
| **`apps.json`** | **공용 프로그램 목록. 새 프로그램은 여기에 한 칸 추가** | **자주** |
| `manifest.json` | "설치 가능한 앱"으로 인식되게 하는 이름·아이콘 설정 | 거의 안 고침 |
| `sw.js` | 인터넷이 느리거나 끊겨도 서랍이 열리게 하는 보조 파일 | 안 고침 |
| `icon-32.png` / `icon-192.png` / `icon-512.png` | 서랍 아이콘 (작은 탭용 / 작업표시줄용 / 설치 화면용) | 안 고침 |

---

## 2. 데이터 흐름

```
[apps.json]  ← 깃허브에 올림 (공용, 모든 컴퓨터가 같은 목록)
     │  (열 때마다 새로 읽음)
     ▼
[index.html] ──합침── [이 컴퓨터에 저장된 내 목록·즐겨찾기·최근 사용]
     │                    (브라우저 localStorage — 이 컴퓨터에만 있음)
     ▼
  화면 표시 → 항목 클릭 → 해당 사이트가 새 탭으로 열림
                          (로그인은 사이트와 브라우저가 알아서 처리)
```

### 교사 / 학생 구분
- `apps.json`의 각 항목에 `"대상"` 값이 있습니다: `"교사"` · `"학생"` · `"공통"`
- **교사용 보기:** 전부 보임 (🔒 = 교사 전용 표시)
- **학생용 보기:** `"학생"`, `"공통"`만 보임
- 학생용 바로 열기 주소: `서랍주소/?mode=student` (이 주소로 설치하면 학생용으로 시작)
- `"대상"`을 안 적으면 **자동으로 "교사"** 로 처리됩니다 (학생에게 업무 사이트가 실수로 노출되지 않게)

## 3. 자주 고칠 곳

### (1) 프로그램 추가 / 주소 입력 → `apps.json`
항목 한 개의 모양:
```json
{
  "이름": "꿈송이 모둠 뽑기",
  "주소": "https://여기에-주소",
  "분류": "수업",
  "아이콘": "🎲",
  "설명": "모둠 편성",
  "대상": "교사",
  "추가일": "2026-11-19"
}
```
- **분류**: `수업` / `업무` / `개인` / `기타` 중 하나 (파랑/초록/주황/회색)
- **아이콘**: 이모지 1개 (윈도우 키 + `.` 으로 입력). 비우면 이름 첫 글자
- **추가일**: 날짜로부터 14일간 빨간 NEW 표시
- **주의:** 항목과 항목 사이에는 쉼표 `,` 가 있어야 하고, **마지막 항목 뒤에는 쉼표를 붙이면 안 됩니다.**
- 지금 파일에서 `"주소": ""` 로 비어 있는 항목은 **주소를 직접 채워 넣어야** 열립니다. (제가 선생님의 실제 주소를 알 수 없어 비워 두었습니다.)

### (2) 색·표시 개수 → `index.html` 위쪽 `<script>` 안
- `CAT_COLOR` : 분류별 색
- `NEW_DAYS` : NEW 표시 기간(일)
- `RECENT_MAX` : 최근 사용 개수

### (3) 아이콘 모양 바꾸기 → `icon-*.png` 3개를 같은 이름으로 교체

## 4. 개인정보 · 오류 위험 지점

| 위험 | 설명 | 대처 |
|---|---|---|
| **apps.json은 누구나 볼 수 있음** | 깃허브 페이지는 주소를 아는 사람은 파일 내용까지 볼 수 있습니다. | **학생·교사 개인정보, 비밀번호, 내부 업무 주소는 넣지 마세요.** 주소만 넣는 구조라 비밀번호는 저장되지 않습니다. |
| 학생용 구분은 "숨김"일 뿐 | 학생용 보기는 화면에서 안 보이게 하는 것이지 접근을 막는 것이 아닙니다. 학생이 apps.json 파일을 직접 열면 교사용 주소도 보입니다. | 정말 보이면 안 되는 주소는 apps.json에 넣지 말고, 내 컴퓨터의 `＋ 추가`(내 목록)로만 넣으세요. |
| 내 목록·즐겨찾기는 컴퓨터별 | `＋ 추가`로 넣은 것과 ⭐는 그 컴퓨터·그 브라우저에만 저장됩니다. 브라우저 방문 기록/사이트 데이터를 지우면 사라집니다. | 오래 쓸 것은 apps.json에 넣으세요. |
| JSON 쉼표·따옴표 실수 | 쉼표 하나만 빠져도 공용 목록 전체가 안 뜹니다. 이때 화면에 "공용 목록을 불러오지 못했습니다" 안내가 뜹니다. | 고친 뒤 목록이 안 뜨면 방금 고친 줄의 쉼표와 따옴표를 확인하세요. 또는 https://jsonlint.com 에 붙여 넣어 검사. |
| 파일을 더블클릭해서 열면 목록이 안 뜸 | 보안 규칙 때문에 컴퓨터 파일로 열면 apps.json을 못 읽습니다. | 반드시 깃허브 페이지 주소(https://…)로 여세요. |
| 로그인이 풀리는 사이트 | 업무포털 등은 일정 시간 뒤 자동 로그아웃됩니다. | 서랍이 아니라 사이트 설정입니다. 서랍은 주소만 열어 줍니다. |
| 설치한 브라우저 | 로그인한 브라우저(크롬/엣지)와 다른 브라우저에서 서랍을 설치하면 로그인이 이어지지 않습니다. | 평소 업무에 쓰는 브라우저에서 설치. |

## 5. 처음부터 올리는 방법 (초보자용, 순서대로)

### A. 깃허브에 올리기
1. https://github.com 에 로그인합니다.
2. 오른쪽 위 **＋** 버튼 → **New repository** 를 누릅니다.
3. **Repository name** 칸에 `drawer` 라고 적습니다. (다른 이름도 가능)
4. **Public** 이 선택된 것을 확인하고, 아래 초록색 **Create repository** 를 누릅니다.
5. 새 화면에서 **uploading an existing file** 이라는 파란 글씨를 누릅니다.
6. 이 폴더 안의 **파일 7개**(index.html, apps.json, manifest.json, sw.js, icon-32.png, icon-192.png, icon-512.png)를 한꺼번에 끌어다 놓습니다. (구조설명.md는 올려도 되고 안 올려도 됩니다.)
7. 아래 초록색 **Commit changes** 를 누릅니다.

### B. 사이트로 만들기 (GitHub Pages)
1. 그 저장소 화면 위쪽 메뉴에서 **Settings** 를 누릅니다.
2. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
3. **Branch** 에서 `None` 으로 되어 있는 것을 **main** 으로 바꾸고 **Save** 를 누릅니다.
4. 1~2분 기다린 뒤 화면을 새로고침하면 위쪽에 `Your site is live at https://아이디.github.io/drawer/` 라고 나옵니다. 이 주소가 서랍 주소입니다.

### C. 작업표시줄에 올리기
1. **크롬**(평소 업무포털에 로그인하는 브라우저)으로 서랍 주소를 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘**(모니터에 아래 화살표 모양)을 누르고 **설치**를 누릅니다.
3. 서랍 창이 따로 뜹니다. 작업표시줄에 생긴 서랍 아이콘을 **우클릭 → 작업 표시줄에 고정**합니다.
4. 이제 서랍 아이콘을 한 번 누르면 목록이 뜨고, 항목을 누르면 사이트가 열립니다.
5. (선택) 창이 너무 크면 한 번만 원하는 크기로 줄이세요. 이후로는 그 크기로 열립니다.
6. (선택) 설정 ⚙️ 에서 "사이트를 연 뒤 서랍 창 자동으로 닫기"를 켜면 시작 메뉴처럼 쓸 수 있습니다.

### D. 새 프로그램 추가하는 법
- **공용(선생님들과 같이):** 깃허브 저장소에서 `apps.json` → 연필 아이콘(Edit) → 항목 추가 → **Commit changes**. 1~2분 뒤 모든 컴퓨터에 반영됩니다.
- **나만:** 서랍 안 `＋ 추가` 버튼에 주소를 붙여넣기.

### E. 서랍을 고쳐서 다시 올렸는데 화면이 그대로일 때
- 서랍 ⚙️ → **목록 새로고침** (apps.json을 고쳤을 때)
- 그래도 안 되면 서랍 창에서 `Ctrl + Shift + R`

## 6. 비슷한 기존 서비스 (참고)
- Windows 10 작업표시줄 도구 모음 (Windows 11에서는 삭제됨)
- 크롬 북마크 폴더 (컴퓨터마다 따로 관리해야 함)
- Symbaloo (링크 타일 모음 서비스)

이 서랍의 차이점: 작업표시줄 고정 + 깃허브로 한 번 고치면 모든 컴퓨터 자동 반영 + 교사/학생 보기 분리.
