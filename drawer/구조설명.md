# 도디쌤 서랍 — 구조 설명서 (개인 서랍 버전)

작업표시줄 아이콘 한 번 → 작은 창에서 내가 넣은 사이트 목록 → 클릭하면 새 탭으로 열림.
(설치형 웹앱 = PWA 방식. 서버·가입·비용 없이 깃허브 페이지만으로 동작)

**기본 사이트는 하나도 없습니다.** 처음 열면 빈 서랍이고, 쓰는 사람이 직접 넣고 뺍니다.

---

## 1. 전체 파일 구조

| 파일 | 역할 | 고치는 빈도 |
|---|---|---|
| `index.html` | 서랍 화면과 모든 동작(검색·탭·즐겨찾기·넣기·수정·빼기·백업) | 기능을 바꿀 때만 |
| `manifest.json` | "설치 가능한 앱"으로 인식되게 하는 이름·아이콘 설정 | 거의 안 고침 |
| `sw.js` | 인터넷이 느리거나 끊겨도 서랍이 열리게 하는 보조 파일 | 안 고침 |
| `icon-32.png` / `icon-192.png` / `icon-512.png` | 서랍 아이콘 | 안 고침 |

※ 사이트 목록 파일은 없습니다. 목록은 각자 컴퓨터에 저장됩니다.

---

## 2. 사용법 (서랍 화면 안에서 전부 해결)

- **넣기:** 오른쪽 아래 `＋ 추가` → 주소 붙여넣기 (이름·이모지·분류는 선택)
- **수정:** 항목 오른쪽 `✎`
- **빼기:** 항목 오른쪽 `✕` → 확인 → 목록에서 사라짐
- **즐겨찾기:** `☆` 를 누르면 맨 위에 모임
- **검색:** 위쪽 검색창 (Enter = 첫 번째 열기, `/` 키 = 검색창으로 이동)
- **백업:** ⚙️ 설정 → `백업 저장` / `백업 불러오기`

---

## 3. 데이터 흐름 — "다른 사람이 같은 주소로 열면?"

```
[깃허브 페이지]  ← 서랍 프로그램(화면)만 들어 있음. 사이트 목록은 없음.
      │  누구나 같은 화면을 받아 감
      ▼
[각자의 컴퓨터·각자의 브라우저]
   └ 브라우저 저장 공간(localStorage)에 "내 목록·즐겨찾기·최근 사용" 저장
```

- **다른 사람이 같은 주소로 열면 빈 서랍이 보입니다.** 내가 넣은 사이트는 보이지 않습니다.
- **같은 컴퓨터, 같은 크롬 프로필**을 함께 쓰면(예: 학교 공용 PC를 같은 계정으로 사용) 내 목록이 보입니다.
- **다른 컴퓨터로는 자동으로 옮겨지지 않습니다.** 옮기려면 `백업 저장` → 파일 전달 → 다른 컴퓨터에서 `백업 불러오기`.
- 크롬/엣지는 달라도 서로 따로입니다. (크롬에서 넣은 목록은 엣지에서 안 보임)

## 4. 자주 고칠 곳

| 하고 싶은 일 | 위치 |
|---|---|
| 분류 이름·색 바꾸기 | `index.html` 위쪽 `<script>` 의 `CATS`, `CAT_COLOR` |
| 최근 사용 개수 | 같은 곳 `RECENT_MAX` |
| 하단 저작권 문구 | `index.html` 아래쪽 `class="wm"` 한 줄 |
| 아이콘 모양 | `icon-*.png` 3개를 같은 이름으로 교체 |

## 5. 개인정보 · 오류 위험 지점

| 위험 | 설명 | 대처 |
|---|---|---|
| 브라우저 데이터 삭제 시 목록 사라짐 | "사이트 데이터/쿠키 삭제"를 하면 내 목록도 지워집니다. | 가끔 `백업 저장`으로 파일을 남겨 두세요. |
| 컴퓨터마다 따로 저장 | 학교 PC와 집 PC의 목록은 서로 다릅니다. | 백업 파일로 옮기기 |
| 공용 PC | 같은 크롬 계정을 여럿이 쓰면 목록이 함께 보입니다. | 개인 사이트는 개인 계정에서만 사용 |
| 주소만 저장 | 서랍은 주소·이름·이모지만 저장합니다. **아이디·비밀번호·학생 정보는 저장하지 않습니다.** | 그래도 백업 파일에는 내 사이트 주소가 담기므로 남에게 보내지 마세요. |
| 로그인이 풀리는 사이트 | 업무포털 등은 일정 시간 뒤 자동 로그아웃됩니다. | 사이트 설정이라 서랍에서 바꿀 수 없음 |
| 설치한 브라우저 | 평소 업무에 쓰는 브라우저에서 설치해야 로그인이 이어집니다. | 로그인하는 브라우저(크롬)에서 설치 |
| 파일로 직접 열기 | 컴퓨터 파일을 더블클릭하면 설치·저장이 불안정합니다. | 반드시 깃허브 페이지 주소(https://…)로 열기 |
| 위험한 주소 | `javascript:` 같은 주소는 자동으로 거부됩니다. | (자동 처리) |

## 6. 설치 방법

1. **크롬**(평소 업무포털에 로그인하는 브라우저)으로 서랍 주소를 엽니다.
2. 주소창 오른쪽 끝 **설치 아이콘**(모니터에 아래 화살표) → **설치**
3. 서랍 창이 따로 뜨면, 작업표시줄의 서랍 아이콘을 우클릭 → **작업 표시줄에 고정**
4. (선택) ⚙️ 설정에서 "사이트를 연 뒤 서랍 창 자동으로 닫기"를 켜면 시작 메뉴처럼 쓸 수 있습니다.

## 7. 수정본을 다시 올리는 방법 (참고)

깃허브 저장소의 `drawer` 폴더에서 파일을 교체하면 1~3분 뒤 반영됩니다.
반영 후에도 화면이 그대로면 서랍 창에서 `Ctrl + Shift + R` 을 누르세요.

## 8. 비슷한 기존 서비스 (참고)
- Windows 10 작업표시줄 도구 모음 (Windows 11에서는 삭제됨)
- 크롬 북마크 폴더 (컴퓨터마다 따로 관리)
- Symbaloo (링크 타일 모음 서비스)

이 서랍의 차이점: 작업표시줄 고정 + 서랍 안에서 바로 넣고 빼기 + 검색·즐겨찾기 + 백업.

## v4 변경 (가독성 개편)
- 즐겨찾기: 화면 맨 위 큰 타일(3열)로 전부 표시, 개수 표시. 별 판정은 `isFav`(주소 끝 `/`·http/https·대소문자 차이 무시)로 통일 → "3개 눌렀는데 2개만 보임" 해결. 같은 주소 중복 항목은 한 개로 합쳐 표시(`allItems`).
- 분류별 접이식 목록(수업/업무/개인/기타, 개수 표시, 접힘 상태 저장 `drawer.open`). 즐겨찾기 항목도 제자리에 그대로 보임(중복 구역 제거).
- 최근 사용은 머리말 아래 한 줄 칩. 수정(✎)·빼기(✕)는 하단 「편집」 버튼을 눌렀을 때만 표시(실수 방지).
- 자주 고칠 곳: 화면 그리기 `render()`, CSS 하단 "v2 가독성 개편" 블록.

## v6
- 즐겨찾기를 큰 타일이 아닌 세로 목록(한 줄에 하나)으로 변경. 서랍에서 찾아지지 않는 즐겨찾기(주소 수정·삭제 등)는 주황 안내 상자에 표시, 「정리하기」로 제거.
