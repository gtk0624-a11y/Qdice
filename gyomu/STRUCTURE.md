# 업무파탈 (Travail Fatal) 구조 설명서

© 김정환 · M.A.D.T (Moral And Digital Teacher)

## 1. 한눈에 보기
빌드 도구가 없는 **순수 HTML·CSS·JS** 앱입니다. 파일을 그대로 깃허브 페이지에 올리면 돌아갑니다.
다른 선생님은 같은 주소를 열어 "빈 수첩으로 시작"을 누르면, **각자의 브라우저에 각자의 자료**로 쓰게 됩니다(내 자료는 공유되지 않음).

## 2. 파일 구조
```
index.html            첫 페이지. 아래 파일들을 순서대로 불러옴
style.css             모든 디자인(색·글꼴·배치). 색은 맨 위 :root 변수
firebase-config.js    동기화 설정 칸(비어 있으면 동기화 꺼짐)
manifest.webmanifest  작업표시줄·홈 화면에 설치(PWA)할 때 쓰는 이름·아이콘 정보
sw.js                 앱 껍데기를 저장해 두는 파일(고치면 VERSION 숫자 올리기)
icons/                앱 아이콘 192, 512
js/core.js            공통 도구, 저장소(localStorage·IndexedDB), 대화상자(ask), 파일 읽기
js/search.js          꿈송이 검색(대충 말해도 찾기), 계획서에서 예산 후보 뽑기
js/sync.js            구글 로그인 동기화(선택)
js/app.js             모든 화면과 버튼 동작
js/pages.js           내 페이지(노션처럼 블록으로 만드는 페이지). app.js 뒤에 불러옴
```

## 3. 데이터 흐름 (교사·학생)
- 이 앱은 **교사 1인용 수첩**입니다. 학생이 접속하는 화면은 없습니다(학생용 연동이 필요하면 별도 프로그램으로 분리하는 것을 권합니다).
- 모든 자료는 `S`라는 하나의 상태(core.js)에 모이고, 바뀔 때마다 `save()`가 브라우저에 저장합니다.
  - **S** (일정·예산·수업·평가·연수·노트 글·내 페이지·업무분장·연락망·서랍) → `localStorage` (작은 글 자료)
  - **LIB** (올린 계획서·회의록·규정에서 뽑은 글자) → `IndexedDB`
  - **필기 그림, 꿈송이 사진** → `IndexedDB`
- 화면은 `S`에서 그때그때 계산합니다. 예) 오늘 게시판의 "예산 잔액"은 장부 숫자를 합해 만든 값이라, 장부만 고치면 모든 화면이 따라 바뀝니다.
- 꿈송이는 S와 LIB를 **조각**으로 쪼개 점수를 매겨 찾습니다(search.js `buildChunks` → `search`).
- 동기화를 켜면 S(잠금 노트 제외)만 구글 클라우드(파이어스토어) `users/{내 계정}` 문서 한 개에 복사됩니다. LIB·필기 그림은 올라가지 않습니다.

## 4. 자주 고칠 곳
| 하고 싶은 일 | 위치 |

| 내 페이지 블록 종류·틀(템플릿) | js/pages.js 맨 위 `BT`, `TEMPLATES` |
| 예산 계산(총액·집행·잔액) | js/search.js `projAlloc`, `projSpent` / js/app.js `budgetView()` |
| 학사일정 읽는 규칙(날짜 모양·학년도 추정) | js/search.js `extractSchedule`, `schoolYearNow` / 확인 창은 js/app.js `scheduleDialog` |
| 연결(페이지·노트↔다른 항목) | js/pages.js `targets`, `linksHtml` |

| 꿈송이가 무시할 말 | js/search.js `STOP` |
| 시험·기본값(수업 45분 등) | js/core.js `DEF` |
| 저작권 표기 | js/app.js `footer()` 와 `welcome()` |

## 5. 개인정보·오류 위험 지점 (꼭 읽기)
1. **학생 이름·성적 점수는 넣지 마세요.** 특히 클라우드 동기화와 Claude 열쇠(AI 답변)를 켠 경우에는 외부 서버로 나갑니다. 불가피하면 노트의 "이 기기에만 보관"을 체크하세요(동기화·AI 전송에서 빠집니다). 단, 올린 문서(자료실)는 "잠금" 기능이 없으니 학생 정보가 든 파일은 올리지 마세요.
2. 내 페이지도 노트처럼 "이 기기에만 보관"을 체크하면 동기화에서 빠집니다.
2. 연락망의 개인 전화번호는 동기화를 켜면 내 구글 계정 클라우드에 저장됩니다. 파이어베이스 보안 규칙(아래 7번)을 반드시 적용하세요.
3. **브라우저 기록·사이트 데이터를 지우면 이 기기의 자료가 사라집니다.** 설정 → "백업 파일 받기"를 가끔 하세요.
4. 폰 인앱 브라우저(카카오톡)는 파일 저장·설치가 제한될 수 있습니다. 크롬이나 삼성 인터넷으로 여는 것을 권합니다.
5. PDF·엑셀 읽기는 처음 쓸 때 인터넷에서 부품(pdf.js, SheetJS)을 내려받습니다. 학교망에서 막히면 텍스트(.txt, .csv)로 저장해 올리세요. 한글(hwp)·워드는 PDF로 저장해서 올려야 합니다.
6. 스캔한 PDF(그림 PDF)는 글자를 읽지 못합니다.
7. 계획서에서 예산을 뽑는 기능은 "항목 + 금액" 모양의 줄을 찾는 방식이라 **틀릴 수 있습니다.** 그래서 확인 창에서 체크한 것만 장부에 들어가게 했습니다. 넣은 뒤 숫자를 꼭 한 번 보세요.
8. 꿈송이는 올린 자료 안에서만 찾습니다. 자료에 없는 내용은 지어내지 않고 "찾지 못했다"고 합니다.

## 6. 학사일정 넣기
캘린더 화면 → "학사일정 파일 올리기"(PDF·엑셀·텍스트) 또는 "붙여넣기". 「3/2 입학식」「7.21~8.20 여름방학」「2026.05.05. 어린이날」 같은 줄을 찾아 확인 창에 보여 주고, 체크한 것만 캘린더에 들어갑니다. 연도가 없으면 3월~다음해 2월 학년도로 짐작하니 확인 창에서 날짜를 꼭 보세요. 같은 날짜·같은 이름은 다시 넣어도 중복되지 않습니다. 월별 표(달 칸 안에 날짜가 따로 있는 모양)는 줄 모양으로 바꿔 붙여야 읽힙니다. 나이스 공식 연동은 아직 없습니다.

## 8. 동기화 켜기 (선택, 처음 한 번만)
1. https://console.firebase.google.com 에서 프로젝트 만들기 → "웹 앱 추가(</>)" → 나오는 설정 값(apiKey 등)을 복사
2. 같은 화면에서 Authentication → 시작하기 → 로그인 방법 → Google 사용 설정
3. Authentication → 설정 → 승인된 도메인에 `내아이디.github.io` 추가
4. Firestore Database → 데이터베이스 만들기 → 규칙 탭에 아래를 붙여 넣고 게시
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
5. `firebase-config.js`의 `null`을 `{ apiKey:"…", authDomain:"…", projectId:"…", appId:"…" }` 로 바꾸고 다시 올리기
6. 앱 → 설정 → "구글로 로그인". 폰·태블릿에서도 같은 구글 계정으로 로그인하면 이어집니다(가장 나중에 저장한 쪽이 이깁니다).

## 9. 깃허브 페이지에 올리기 (초보자용)
1. github.com 에 로그인 → 오른쪽 위 `+` → New repository → 이름 `travail-fatal`, Public → Create
2. 만들어진 저장소에서 "uploading an existing file" 클릭
3. 이 zip을 **풀어서** 안의 파일·폴더(index.html, js 폴더, icons 폴더 …)를 전부 끌어다 놓기 → Commit changes
4. Settings → Pages → Branch를 `main` / `/(root)` 로 선택 → Save
5. 1~2분 뒤 `https://내아이디.github.io/travail-fatal/` 이 열립니다. 이 주소를 다른 선생님께 나누어 주세요.
6. 크롬에서 열고 주소창 오른쪽 "설치" 아이콘(또는 메뉴 → 앱 설치)을 누르면 작업표시줄·홈 화면에 고정됩니다.

## 10. 다른 선생님이 쓰는 법 (빈 템플릿)
주소를 열면 환영 화면이 나옵니다. 이름·학교·교과·담당 반을 적고 "빈 수첩으로 시작"을 누르면 끝입니다. 자료는 각자의 기기(또는 각자의 구글 계정)에만 저장됩니다. 필요 없는 줄은 설정에서 끌 수 있습니다.

## 추가 (연수 이수번호 · 챗봇 범위 · 새 학년도)
- 연수: 이수 체크 시 이수일이 자동 기록되고, 오늘 게시판 연수 줄에서 이수번호를 바로 입력합니다 (`training.certNo`, `doneDate`).
- 꿈송이 검색 대상: 일정·학사일정·할 일, 시간표(요일별), 공문 접수·처리 수, 내 정보, 연수(이수번호 포함), 예산, 메모, 내 페이지, 연결, 업무분장, 연락망, 자료실 문서, 수업 진도, 평가, 서랍. 검색 대상이 아닌 것은 손글씨 그림뿐입니다.
- 결과 출력: 복사 / 문서로 내보내기 / 인쇄·PDF.
- 설정 > 새 학년도 시작하기 (`A.newYear`): 백업 후 시간표·일정·진도·평가·예산·연수·공문·업무분장·연락망 초기화. 메모·페이지·서랍·자료실·내 정보는 유지.

## 지난 학년도 보관함 (읽기 전용)
- 설정 > 지난 학년도 보관함에서 예전 백업(.json)을 넣으면 IndexedDB `arch`에 따로 저장됩니다. 지금 데이터(`S`)와 섞이지 않습니다.
- 보기: `#/arch/<id>` (`archView`, 항목별 토글). 꿈송이는 현재 데이터와 보관본을 함께 검색하며 출처 앞에 `[2026학년도]`가 붙습니다.
- 보관함은 기기 안에만 저장되고 Firebase 동기화 대상이 아닙니다. 기기를 바꾸면 백업 파일을 다시 넣어야 합니다.
- 개인정보: 보관본에는 잠근 메모도 들어 있으므로 백업 파일 관리에 유의하세요.

## 제목 · 도디쌤 이미지 · 워터마크
- 맨 위 제목 앞에 항상 도디쌤 이미지가 나옵니다 (올리지 않으면 기본 그림). 설정에서 이미지 교체 가능, IndexedDB `logo`에 저장됩니다.
- 제목·부제는 제목을 누르거나 ✎를 눌러 고칩니다 (`profile.title`, `profile.sub`). 브라우저 탭 이름도 따라갑니다.
- 워터마크: 화면 전체에 옅게 깔리고 인쇄에도 나옵니다. **작품 표시이므로 끄기·글자 변경 기능 없음(항상 표시, core.js wmUrl).**

## 디자인: 교무수첩 스타일
- 스프링 제본 구멍, 빨간 여백선, 줄 노트, 책갈피 리본, 색깔 인덱스 탭, 손글씨 제목(나눔펜스크립트). 모두 style.css 맨 아래 "교무수첩 스타일" 블록에서 바꿉니다.
- 오늘 화면은 왼쪽 면에 월 달력(`miniCal`)과 이번 주 기한 메모지, 오른쪽 면에 게시판 줄이 놓입니다. 폰에서는 한 줄로 쌓입니다.
- 기본 로고는 도디쌤 이미지(core.js의 `DEFLOGO`)입니다.

## 디자인 템플릿 30가지
- 설정 > 디자인 고르기. 선택값은 `profile.theme`에 저장되어 기기 동기화·백업에 따라갑니다.
- 템플릿 목록은 core.js의 `THEMES` 배열 한 줄씩입니다. 새 템플릿은 줄 하나만 추가하면 설정 화면에 자동으로 나타납니다 (책상색, 종이색, 글자색, 포인트색, 탭 방식, 글꼴). 어두운 템플릿은 줄 끝에 `, 1`을 붙입니다.

## 꿈송이 챗봇 버튼
- 오른쪽 아래에 꿈송이 그림이 떠 있고 "무엇이든 물어보세요!" 말풍선이 붙어 있습니다 (눌러도 열립니다). 기본 그림은 core.js의 `DEFMASCOT`이고, 설정에서 다른 그림으로 바꿀 수 있습니다.

## 글씨체 50가지 · 스티커 · 챗봇 디자인
- 글씨체: 설정 > 글씨체 고르기에서 본문·제목을 따로 고릅니다 (`profile.bfont`, `hfont`). 목록은 core.js의 `FONTS50` (구글 폰트 37개 + 프리텐다드·나눔·지마켓 등 CDN 13개, 모두 무료·오픈 라이선스). 고른 글꼴만 인터넷에서 불러옵니다. 오프라인이면 기본 글꼴로 보입니다.
- 스티커 (js/stickers.js): 캘린더 날짜(`S.stk`)와 내 페이지 '스티커' 블록에 붙입니다. 테이프·라벨 직접 그림 + 이모지 약 2,000개 + 내가 올린 그림(기기 안 IndexedDB `mystk`, 동기화·백업 제외). 캔바 스티커 묶음을 자동으로 가져오지는 않으며, 캔바에서 저장한 PNG를 올려 쓰는 방식입니다.
- 챗봇 화면은 규정줍줍 디자인(남색 머리, 꿈송이 얼굴, 노란 번호표, 파란 출처 띠)이며 디자인 템플릿을 바꿔도 같은 모양입니다. 스타일은 style.css 맨 아래 "꿈송이 챗봇" 블록입니다.

## 기기 연동 (컴·폰·태블릿) — js/cloud.js
- 설정 > 기기 연동 켜기에서 연동 암호(8자 이상)를 정하고, 모든 기기에 똑같이 입력하면 같은 수첩이 열립니다. 구글 로그인이 필요 없습니다.
- 내용(수첩 데이터, 자료실, 손글씨, 내 스티커, 꿈송이·도디쌤 그림, 지난 학년도 보관함)은 이 기기에서 AES-256으로 잠근 뒤 올라가며, 서버에는 읽을 수 없는 글자만 있습니다. 서버 경로도 암호에서 계산한 값이라 추측할 수 없습니다. 암호를 잊으면 복구할 수 없습니다.

**작업표시줄 설치·위젯 버튼** — 설정의 "작업표시줄에 고정" 안내 칸(app.js `.guide`) 위에 `setui.js`가 [앱으로 설치하기]·[위젯 열기] 버튼을 붙입니다. 설치는 PWA(manifest.webmanifest) 방식이고, 작업표시줄 아이콘 오른쪽 클릭 메뉴에 "위젯 열기"(manifest `shortcuts`)가 나옵니다.
**위젯** — `widget.html`은 본 앱과 같은 `localStorage`(`travailfatal.v1`)를 **읽기만** 합니다(본 앱 자료를 덮어쓰지 않으려고). `allEvents()`와 비슷한 계산이 `js/widget.js`에 복사되어 있으니 **기한 종류를 추가하면 두 곳을 같이 고치세요.**
**자주 고칠 곳**: 알림 대상 종류 `dday.js ALARM_KINDS` / 알림 기본 일수 `alarmDays()` / 알림 막대 모양 `style.css` 끝의 `#alarmbar` / 위젯 모양 `widget.html` 안 `<style>`.
**위험 지점**: ① 위젯·알림은 같은 브라우저·같은 주소에서만 자료를 봅니다(다른 브라우저·기기는 비어 보임). ② 닫혀 있는 동안은 알림이 가지 않습니다. ③ `sw.js`의 `FILES`에 새 파일을 넣고 `VERSION`을 올려야 설치한 앱에 반영됩니다.
