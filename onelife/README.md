## 1. 전체 파일 구조

```
onelife/
├─ index.html    ← 프로그램 본체 (게임 엔진 + 학생 화면 + 교사 화면 + 내용 편집 + 저장)
├─ content.js    ← 교과 내용: 22단원 사건 이야기, 54차시 글쓰기 문항, RAFTS, 사상가 카드
├─ game.js       ← 게임 규칙: 주사위 판정·실패 결과, 짝 딜레마, 공동체 기금, 운명 카드,
│                  위기, 진로, 비밀 목표, 재능 카드, 숫자 균형(난이도)
├─ teacher.html  ← 교사 화면 바로가기
└─ README.md     ← 이 문서
```

교사 화면 **✏️ 내용 편집**에서 저장한 편집본(단원·운명 카드·이미지·게임 이름)은 Firebase `rooms/OLCONTENT/default`에 저장됩니다. 게임 이름은 `…/title`에 저장되며, 기본 이름은 index.html의 `TITLE0`입니다. 편집본은 파일 내용보다 우선 적용되며, 모든 반이 함께 씁니다.

## 2. 게임 규칙 (한 단원 = 한 시기 = 약 20분)

| 단계 | 학생이 하는 일 | 쪼는 맛 |
|---|---|---|
| ⏰ 시작 | 시기를 시작하면 체력·마음·관계·돈이 저절로 줄어듦 | 가만히 있으면 무너짐 |
| 🗓️ 시간 쓰기 | 시간 토큰(1학년 6개, 2학년 7개)을 공부·일·친구·쉼·봉사·운동에 나눔 | 다 할 수 없음, 능력을 키우려면 무언가를 포기 |
| 🎲 인생 사건 | 딜레마 선택 → 판정이 있으면 주사위 2개 + 능력치 ≥ 목표면 성공 | 옳은 선택도 실패할 수 있음, 능력 부족·비용으로 잠긴 선택지, 제한 시간 |
| 🤝 짝 딜레마 | 교사가 정한 짝과 동시에 협력/배신 | 믿을까, 배신할까 |
| 🏘️ 공동체 기금 | 돈 0~3을 냄 → 교사 결산 → 목표 미달이면 모두 손해 | 공유지의 비극: 안 낸 사람도 결과를 함께 받음 |
| 📊 결산 | 게이지가 0이 되면 **위기** | 번아웃·마음의 겨울·고립·빚 |

- **위기와 극복**: 깨달은 점을 한 문장 쓰고 극복 방법을 고릅니다(판정 또는 대가). 극복하면 **극복 카드**를 얻어 더 강해집니다. 위기를 극복하기 전에는 다음 시기로 갈 수 없습니다.
- **성장**: 경험치(사건·글쓰기·통과·위기 극복)가 쌓이면 레벨업하고, **재능 카드** 3장 중 1장을 고릅니다.
- **운명 카드**: 교사가 반 전체, 무작위 3명, 또는 고른 학생에게 실시간으로 보냅니다(전염병, 경제 위기, 전학, 장학금 등 16장).
- **비밀 인생 목표**: 부·인정·사랑·정의·지혜·자유 중 하나입니다. 다른 학생은 모르고 교사만 봅니다. 2학년 끝 **엔딩 제목**이 이 목표로 정해집니다.
- **2년 구조**: 1학년(7~19살)이 끝나면 능력치로 열리는 **진로**(연구자, 돌봄, 활동가, 사업가, 예술가, 기술자, 교육자)를 고르고 **이어하기 코드**를 받습니다. 2학년(20~80살)에서는 진로마다 **그 길에만 있는 선택지**가 열립니다. 2학년은 판정 목표가 +2 높습니다.
- **글쓰기(관문)**: 사건을 겪으면 ✏️ 차시 글쓰기가, 시기를 마치면 📝 RAFTS 단원 글쓰기가 열립니다. 교사가 하이러닝 확인 후 ✅ 통과를 줘야 다음 시기가 열립니다(관문은 끌 수 있음).

## 3. 교사 진행 순서

1. **🎛️ 진행·게임**에서 수업한 시기까지 [열기]를 누르고 오늘 차시를 고릅니다.
2. 학생이 시간 쓰기와 인생 사건을 합니다. 필요하면 **⏸ 갈림길**로 반 전체를 멈추고 분포를 공개해 토론합니다.
3. **[짝 정하기]** → 학생이 짝 딜레마를 합니다.
4. 학생이 기금을 내면 **[공동체 결산하기]**를 누릅니다.
5. 중간중간 **🃏 운명 카드**를 보냅니다.
6. **📚 글 모아보기 → ZIP** → 하이러닝에 업로드 → **👥 학생 현황**에서 📤 업로드 표시와 ✅ 통과를 줍니다.

## 5. 자주 고칠 곳

| 고치고 싶은 것 | 가장 쉬운 방법 | 파일로 고칠 때 |
|---|---|---|
| 사건 상황·선택지·성공/실패 이야기·판정 난이도·이미지 | ✏️ 내용 편집 | `content.js`의 `ev` + `game.js`의 `U.단원.c` |
| 짝 딜레마·공동체 기금 문장 | ✏️ 내용 편집 | `game.js`의 `U.단원.pair`, `cm` |
| 운명 카드 | ✏️ 내용 편집 → 🃏 운명 카드 편집 | `game.js`의 `FATE` |
| 차시 문항·필수 개념어·RAFTS | ✏️ 내용 편집 | `content.js`의 `lessons`, `rafts` |
| 전체 난이도(시간 토큰 수, 감소량, 2학년 판정 +2) | 파일 | `game.js`의 `TOKENS`, `DECAY`, `DC_PLUS` |
| 활동 효과·재능 카드·진로·위기 | 파일 | `game.js`의 `ACTS`, `PERKS`, `PATHS`, `CRISES` |
| 마무리 글쓰기 문항 | 파일 | `content.js` 맨 아래 `ENDINGS` |
| 교사 비밀번호·Firebase | 파일 | `index.html`의 `TEACHER_PIN`, `FIREBASE_CONFIG` |

파일을 고칠 때는 따옴표 안의 글자와 숫자만 고치세요. 쉼표나 괄호를 지우면 화면이 하얗게 나옵니다.

## 6. 개인정보·오류 위험 지점

**개인정보**
- 실명을 받지 않습니다. 번호와 인생 속 인물 이름만 받습니다. 학생이 글에 실명이나 실제 사연을 쓰지 않도록 안내해 주세요.
- 학생 글은 서버에 **임시 보관**됩니다. 🗂️ 보관·삭제에서 학기 종료일을 넣으면, 정한 날이 지난 뒤 **📤 업로드 표시된 글만** 삭제됩니다. 이 삭제는 교사 화면을 여는 순간 실행되며, 7일 전부터 경고가 뜹니다.
- Firebase 규칙이 `rooms` 아래를 열어 둔 구조입니다(국가 만들기와 동일). 그래서 민감한 내용은 쓰지 않는 것이 가장 확실한 보호입니다.
- 짝 딜레마에서는 기본으로 **인물 이름만** 보입니다(실제 번호는 숨김).

**오류·운영 위험**
- 이미 학생이 겪은 사건의 선택지 **순서를 바꾸거나 지우면** 기록이 엉킵니다. 편집 화면에 경고가 뜹니다.
- **제한 시간**이 켜져 있으면, 학생이 사건 화면을 떠났다가 돌아올 때 시간이 이미 지나 있을 수 있습니다. 시간이 다 되면 무작위로 선택되고 주사위 -2가 붙습니다. 갈림길이나 운명 카드가 떠 있는 동안에는 시간이 멈춥니다.
- 짝이 결석하거나 늦으면 학생은 [기다리지 않고 다음으로]를 누를 수 있습니다. 결과는 짝이 고르는 대로 나중에 반영됩니다.
- 운명 카드의 위기가 겹치면 게이지가 0이 되기 쉽습니다. 한 시기에 1~2장이 적당합니다.
- 카카오톡 안에서는 [파일로 저장]이 안 될 수 있습니다. 이때는 [복사하기]를 쓰세요.
- 학교 와이파이가 Firebase를 막으면 "체험 모드"가 뜹니다. 수업 전에 태블릿 한 대로 먼저 확인하세요.
- 30명이 동시에 쓰는 상황과 실제 태블릿 화면은 아직 시험하지 않았습니다.
