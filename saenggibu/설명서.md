## 1. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 프로그램 전체(화면·기능·도디쌤 이미지 포함). 이 파일 하나만 깃허브에 올리면 됩니다. |
| `현황판_AppsScript.gs` | 담당자 구글 시트에 붙이는 코드. 입력 현황(숫자)을 받고, 수정 요청(점검→수정→확인)을 주고받습니다. |
| `생기부_입력양식.xlsx` | 선생님들께 나눠 줄 입력 양식(명단·영역별 내용·바이트 확인). 사이트에서도 내려받기 단추로 받을 수 있습니다. |
| `설명서.md` | 이 문서 |

`index.html` 안의 코드는 번호가 붙은 12개 구역으로 나뉩니다.

| 구역 | 내용 |
|---|---|
| 1 | 계산 함수: 바이트 계산, 자동 교정, 기재요령 점검, 날짜 읽기, 수업일수 계산 |
| 2 | 데이터 구조와 저장(브라우저 저장소) |
| 3 | 공통 도구(복사, 파일 읽기, 알림 문구) |
| 4 | 입력 카드(글 쓰는 칸 하나) |
| 4 | (같은 구역) 네이버 맞춤법 검사기 연결: 글을 300자 이하 조각으로 나눠 복사 → 네이버 창 열기 → 교정본 붙여넣어 적용 |
| 10-2 | 수정 요청(생기부 메신저): 받기·보내기·수정 완료·확인·재요청·담당자 현황·알림 |
| 5~10 | 화면 7개(수정 요청 탭 포함): 영역별 입력 / 학생별 입력 / 점검·현황 / 일정(디데이·달력) / 시수 / 설정·백업 |
| 11 | 버튼·입력 처리 |
| 12 | 시작 |

## 2. 데이터 흐름

```
[교사 PC 브라우저]
  학생 명단·생기부 내용·일정·시수
        │  (저장: 이 PC 브라우저 안에만)
        ├──▶ 엑셀 백업 파일(.xlsx)  ← 다른 PC로 옮길 때도 이 파일
        ├──▶ 클립보드 복사 ──▶ 나이스 입력칸에 Ctrl+V
        └──▶ 숫자만 전송 ──▶ [담당자 구글 시트 "현황" 탭]
              (교사 이름, 학급, 항목, 학생 수, 작성·완료·초과 수)
```

- 학생 이름과 생기부 문장은 인터넷으로 나가지 않습니다.
- 구글 시트로 가는 것은 숫자와 교사 이름뿐입니다.
- 학생용 화면은 없습니다. 교사 혼자 쓰는 도구입니다.

## 3. 자주 고칠 곳

| 하고 싶은 일 | 방법 |
|---|---|

| 내년 기재요령 반영 | 같은 화면에서 한도를 고친 뒤 **규칙 파일 내보내기** → 다른 선생님은 **규칙 파일 등록**. |
| 맞춤법 규칙 추가 | **설정·백업 → 내 교정 규칙**. 기본 규칙을 고치려면 코드에서 `SPELL_RULES` 를 찾습니다. |
| 경고 문구·금지 표현 | **내 금지어**에 추가. 기본 점검을 고치려면 코드에서 `LINT_RULES` 를 찾습니다. |
| 세특 입력 대상 30% 등 비율 | 프로그램 **설정·백업 → 기재요령 규칙** 표의 "입력 대상(%)" 칸. 코드에서는 `ratioOf` |

| 네이버 조각 크기(300자) | 코드에서 `NV_MAX` 를 찾습니다. |
| 색·글자 크기 | 코드 맨 위 `<style>` 안 `:root{...}` 줄. |

## 4. 개인정보·오류 위험 지점

1. **공용 PC**: 내용이 그 PC 브라우저에 남습니다. 공용 PC에서 썼다면 백업 후 **설정·백업 → 모든 자료 지우기**를 누르세요.
2. **백업 파일**: 엑셀·json 백업에는 학생 이름과 내용이 그대로 들어 있습니다. 업무용 PC나 교육청 드라이브에만 두고, 카카오톡·개인 메일로 보내지 마세요.
3. **브라우저 기록 삭제**: 인터넷 사용 기록(사이트 데이터)을 지우면 내용도 지워집니다. 화면 오른쪽 위 "백업 n일 전" 표시를 보고 자주 백업하세요.
4. **브라우저·PC마다 따로 저장**: 크롬에서 쓴 내용은 엣지나 다른 PC에서 보이지 않습니다. 엑셀 백업으로 옮깁니다. 카카오톡에서 링크를 눌러 열면 카톡 속 브라우저에 따로 저장되니, 실제 작성은 크롬이나 엣지에서 하세요.
5. **바이트 한도**: 기본값은 2026학년도 기준 추정값입니다. 기재요령의 "영역별 입력 가능 최대 글자수" 표와 실제 나이스 화면으로 반드시 대조하세요. 2026년에 줄어든 한도(진로 500자, 행특 300자)가 나이스에 반영됐는지도 확인이 필요합니다.
6. **엔터 바이트**: 기재요령은 1바이트로 적고, 현장 계산기들은 2바이트로 셉니다. 기본은 안전한 2바이트이고, 복사할 때 줄바꿈을 띄어쓰기로 바꾸므로 실제로는 문제가 되지 않습니다.
7. **자동 교정의 한계**: 맞춤법은 "틀린 형태가 분명한 표현" 약 70가지와 공백·기호만 고칩니다. 문맥을 봐야 하는 맞춤법(로서/로써, 든지/던지 등)은 잡지 못합니다. 고친 내용은 칸 아래에 표시되고 되돌릴 수 있습니다.
8. **기재요령 경고**: 대학명·교외 수상·어학시험·부모 직업·영문·특수문자 등을 낱말로 찾는 방식이라, 문제없는 문장에도 경고가 뜰 수 있고 못 잡는 경우도 있습니다. 최종 판단은 교사가 합니다.
9. **현황판 주소·암호**: 주소와 암호를 아는 사람은 누구나 숫자를 보낼 수 있습니다. 교직원 외에는 알리지 마세요.
11. **네이버 맞춤법 검사**: 이 기능을 쓰면 그 글이 네이버로 넘어갑니다(선생님이 직접 붙여넣는 방식). 글에 학생 이름이 들어 있으면 지우고 검사하세요. 네이버는 한 번에 300자까지만 검사하므로 프로그램이 문장 단위로 나눠 줍니다. 네이버 검사기는 특수문자를 지울 수 있으니 적용 뒤 한 번 읽어 보세요.
10. **시수 파일**: PDF·엑셀을 읽습니다. "날짜와 내용이 한 줄에 있는 표"나 "3월 아래 2(월) 입학식" 꼴만 읽고, 달력 모양 표·스캔한 그림 PDF·한글(hwp)은 읽지 못합니다. PDF는 표 칸이 여러 줄로 나뉘면 내용이 잘리거나 날짜가 빠질 수 있습니다. 읽은 결과는 반영 전에 표로 보여 주므로 분류와 빠진 날짜를 꼭 확인하세요.

## 5. 깃허브에 올리기 (처음 하는 분 기준)

1. 크롬에서 `github.com` 에 로그인합니다.
2. 오른쪽 위 **+** 를 누르고 **New repository**(새 저장소)를 누릅니다.
3. **Repository name**(저장소 이름)에 `saenggibu` 라고 적습니다.
4. **Public**(공개)을 고릅니다. 프로그램 코드만 공개되고, 학생 자료는 올라가지 않습니다.
5. 맨 아래 초록색 **Create repository**(저장소 만들기)를 누릅니다.
6. 다음 화면에서 **uploading an existing file**(기존 파일 올리기) 글자를 누릅니다.
7. `index.html` 파일을 화면에 끌어다 놓습니다.
8. 아래 초록색 **Commit changes**(변경 사항 저장)를 누릅니다.
9. 위쪽 메뉴에서 **Settings**(설정) → 왼쪽 **Pages**(페이지)를 누릅니다.
10. **Branch**(가지)에서 `main` 을 고르고 **Save**(저장)를 누릅니다.
11. 1~2분 뒤 `https://gtk0624-a11y.github.io/saenggibu/` 로 들어가면 열립니다.

수정할 때는 저장소에서 `index.html` 을 누르고 → 연필 모양 → 새 내용을 붙여넣고 → **Commit changes** 를 누릅니다. 써 둔 생기부 내용은 지워지지 않습니다.

## 6. 처음 쓰는 순서

1. **명단 넣기**: 처음 화면에서 **명단 엑셀 파일 올리기**. 학년·반·번호·이름(또는 학번·이름) 칸만 있으면 칸 순서·다른 칸·여러 반 섞임과 상관없이 알아서 정리합니다.
2. **설정·백업 → 기재요령 규칙**: 항목과 한도를 확인합니다. 필요 없는 항목은 지우고, 다른 과목 세특은 **항목 추가**.
3. **영역별 입력**: 위쪽 큰 단추로 학급과 영역을 고르고 학생별로 씁니다. 칸을 벗어나면 자동 교정됩니다.
4. **나이스용 복사** → 나이스 입력칸에서 Ctrl+V. 복사한 칸에는 "복사함" 표시가 붙습니다.
5. 끝나면 **설정·백업 → 엑셀로 백업 받기**.

이미 엑셀에 써 둔 내용이 있으면: 첫 줄을 `학년 | 반 | 번호 | 이름 | 항목 이름…` 으로 맞추고 **엑셀 백업 불러오기**로 한 번에 넣을 수 있습니다.

## 7. 담당자 점검 시트에 코드 붙이기 (학교에서 쓰던 "생활기록부 점검" 구글 시트 그대로)

새 시트를 만들 필요 없이, 학교에서 쓰던 점검 시트(점검일자 · 학번 · 이름 · 오류(확인) 분야 · 상세 분야 · 오류(확인) 내용 · 변경 후 · 담당교사 반영 날짜 · 담임 반영 확인 · 생기부 담당자 확인 · 비고)에 코드를 붙입니다. 코드가 이 칸들이 있는 탭을 스스로 찾습니다(체크리스트 같은 다른 탭은 건드리지 않음).

1. 점검 구글 시트를 엽니다(테스트용 사본으로 먼저 해 보세요).
2. 위 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 처음 보이는 코드를 모두 지우고 `현황판_AppsScript.gs` 내용을 전부 붙여넣습니다.
4. 맨 위 `var KEY = '여기에암호';` 의 `여기에암호` 를 원하는 단어로 바꿉니다.
5. 디스크 모양(저장) → 함수 고르는 칸에서 `setup` → **실행**. 권한 창이 뜨면 본인 계정 → **고급** → **(안전하지 않음)으로 이동** → **허용**.
   - 점검 탭 맨 오른쪽에 숨긴 칸 2개(도우미ID·요청자)가 생기고, `현황`·`담당교사` 탭이 생깁니다.
6. **배포 → 새 배포** → 톱니바퀴 → **웹 앱** → 실행: `나`, 액세스: `모든 사용자` → **배포** → 웹 앱 URL 복사.
7. 생기부 도우미 **설정·백업 → 담당자 시트 연결**에 교사 이름·웹앱 주소·암호를 넣고 **연결 시험** → **학교 전용 링크 복사** → 업무메신저로 선생님들께 보냅니다.
8. 담당자는 같은 칸에서 **담당자 모드**를 켭니다.

**테스트 시트 → 진짜 시트**: 진짜 시트에 1~6을 똑같이 하고, 새 웹앱 주소로 학교 전용 링크를 다시 만들어 보내면 됩니다. 선생님들이 새 링크로 열면 자동으로 넘어가고 테스트 기록은 비워집니다.
코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**.

## 8. 독서기록 받기 (학생이 구글 폼으로 입력)

손글씨 사진을 읽는 대신, 학생이 책 제목과 지은이를 직접 입력하게 하고 그 결과를 프로그램에 불러옵니다.

### 폼 만들기 (한 번만)

1. 크롬에서 `forms.google.com` 에 들어가 **+ 새 양식**(빈 양식)을 누릅니다.
2. 제목을 `독서기록` 으로 적습니다.
3. 질문을 아래 6개로 만듭니다. **질문 이름은 그대로** 적어야 프로그램이 알아봅니다.

| 질문 이름 | 유형 | 설정 |
|---|---|---|
| 학년 | 객관식 | 보기: 1, 2, 3 |
| 반 | 객관식 | 보기: 1, 2, 3 |
| 번호 | 단답형 | 점 3개 → 응답 확인 → 숫자 → 정수 |
| 이름 | 단답형 | |
| 책 제목 | 단답형 | |
| 지은이 | 단답형 | |

4. 질문마다 오른쪽 아래 **필수**를 켭니다.
5. 오른쪽 위 **게시**(또는 보내기) → 링크 모양 → **URL 단축** → 복사해서 학생들에게 알려 줍니다. QR로 띄워도 됩니다.
6. 학생은 **책 한 권마다 한 번씩** 제출합니다.

### 프로그램에 넣기

1. 폼 화면 위쪽 **응답** 탭 → **Sheets에 연결**(초록색 표 모양)을 누릅니다.
2. 열린 구글 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 을 누릅니다.
3. 생기부 도우미 **설정·백업 → 독서기록 불러오기**에서 그 파일을 올립니다.
4. 넣을 내용과 경고(명단에 없는 번호, 이름이 다른 학생)를 확인하고 **이대로 넣기**를 누릅니다.
5. **영역별 입력** 탭에서 항목을 **독서활동상황**으로 바꾸면 학생별로 `책 제목(지은이), 책 제목(지은이)` 꼴로 들어가 있습니다.

같은 파일을 다시 올려도 이미 들어간 책은 다시 들어가지 않습니다. 학기 중에 여러 번 받아도 됩니다.

### 위험 지점

- 학생이 번호를 잘못 적으면 다른 학생에게 들어갑니다. 이름이 명단과 다르면 경고가 뜨니 그때 확인하세요.
- 책 제목·지은이 오타는 그대로 들어갑니다. 넣은 뒤 작성 탭에서 한 번 훑어보세요.
- 구글 폼 응답(학생 이름·읽은 책)은 선생님 구글 드라이브에 저장됩니다. 학교 구글 계정으로 만드는 것이 안전합니다.
- 독서활동상황의 기재 형식과 한도(기본값 1,500B로 넣어 둠)는 2026 기재요령 독서활동상황 쪽에서 확인하고, 다르면 설정에서 고치세요.

## 9. 완료 표시와 빠진 입력

- **완료 기준**: 영역마다 "입력 대상(%)"이 있습니다. 전원 쓰는 영역은 100%, 세특은 30%가 기본입니다. 학급에서 그 비율만큼 쓰면 영역 단추와 현황표에 **✔완료**가 붙습니다.
- **30% 넘음 알림**: 세특에서 목표 인원을 채우는 순간 "완료", 그보다 더 쓰면 "30%를 넘었습니다"가 화면 아래에 뜹니다. 위쪽 상자에는 학급과 학년 전체 비율이 같이 나옵니다.
- **빠진 입력**: 점검·현황 탭 **빠진 입력**에 학급·영역별로 아직 안 쓴 학생이 나옵니다. 이름을 누르면 그 학급·영역의 미작성 학생만 모아 보여 줍니다. 학생별 입력 탭에서는 그 학생의 빠진 영역이 맨 위에 나옵니다.
- 내가 쓰지 않는 영역은 설정에서 "내 담당"을 끄면 빠진 입력 목록에 나오지 않습니다.
- **위험 지점**: 30%는 기본값일 뿐입니다. 실제 입력 대상 범위는 학교 학업성적관리위원회가 정하므로 학교 기준으로 고치세요. 비율 계산은 올림입니다(28명×30% = 8.4 → 9명).

## 10. 엑셀 백업에 들어가는 것

엑셀 백업 파일 하나에 선생님이 입력한 것이 전부 들어갑니다.

| 시트 | 내용 |
|---|---|
| 생기부 | 학생 × 영역 입력 내용 |
| 바이트 | 칸마다 바이트 |
| 완료여부 | 완료 체크 |
| 나이스복사 | 나이스용 복사를 누른 시각 |
| 항목한도 | 영역 이름·한도·입력 대상(%)·내 담당 |
| 일정 | 일정·메모·끝남 |
| 휴업일 / 시수표 / 동아리 | 시수 탭 자료 |
| 교정규칙·금지어 | 내가 만든 교정 규칙과 금지어 |
| 설정 | 교사 이름·학년도·엔터 바이트·현황판 주소와 암호 등 |

- **불러오기**: _복원용 시트가 있으면 전부 되살리고, 그 위에 생기부·완료여부 시트 내용을 덮어씁니다. 그래서 엑셀에서 내용 칸을 고쳐도 반영됩니다. 다른 시트(일정·시수표 등)를 엑셀에서 고친 것은 반영되지 않으니 프로그램에서 고치세요.
- **위험 지점**: 이 파일에는 학생 이름·생기부 내용과 함께 현황판 암호도 들어 있습니다. 업무용 PC나 교육청 드라이브에만 보관하세요.

## 11. 수정 요청 — 생기부 메신저 (학교 점검 시트 그대로)

### 흐름
```
[점검자: 담임·담당자]  점검 시트에 줄 적기 (프로그램 "점검 요청 보내기" 또는 시트에 직접)
        │  분야·상세 분야로 담당교사를 찾음
[담당교사]  🛠 팝업 → 고치러 가기 → 고친 뒤 "나이스용 복사" → "반영 완료를 적을까요?" [확인]
        │  시트 "담당교사 반영 날짜"에 오늘 날짜
[담임]      ✔ "반영 완료 — 담임 확인 차례" 팝업 → 나이스에서 보고 [담임 확인] (또는 [재요청])
        │  시트 "담임 반영 확인"에 오늘 날짜
[생기부 담당자]  ✔ "담당자 확인 차례" 팝업 → [담당자 확인] (여러 건 한꺼번에 가능)
        │  시트 "생기부 담당자 확인"에 ✔ 날짜 → 끝
```
- 비고에 "오류아님"이 있으면 끝난 것으로 봅니다.
- 담당교사 반영 날짜 없이 담임 확인만 된 줄은 담당자 화면에 **"담당교사 반영 체크 없이 넘어간 줄"**로 따로 보입니다(체크를 안 하는 문제를 잡는 곳).

### 각 선생님이 처음 한 번: "내 담당" 정하기
- 수정 요청 탭 맨 위(또는 설정·백업 → 담당자 시트 연결)에서 **분야 · 상세 분야**를 정합니다. 예) 교과세특 · 사회, 자유학기 · 주제(사회), 스포츠동아리 · 보드게임.
- **내 영역에서 자동으로** 단추: "세특: 사회" 같은 내 영역을 보고 교과세특·사회를 자동으로 넣습니다. 동아리는 직접 더해야 합니다.
- 담임이면 **담임 학급**을 고릅니다. 그 반 학생 줄이 반영되면 담임 확인 알림이 옵니다.
- 정한 내용은 시트 `담당교사` 탭에 모여, 담당자가 누가 무엇을 맡는지 볼 수 있습니다.

### 화면
- ① 내가 고칠 것 · ② 담임 확인(내 반) · ③ 점검 요청 보내기(한 건 / 엑셀 6칸 여러 건: 학번·이름·분야·상세·오류 내용·변경 후) · ④ 내가 보낸 요청 · ⑤ 담당자(분야별 단계 현황, 담당자 확인, 체크 없이 넘어간 줄, 미반영, 독촉 메시지, 시트 기록 지우기)
- 맨 위 🛠 칩과 배너에 "고칠 것 n · 확인할 것 n"이 늘 보입니다. 알림을 켜 두면 팝업이 뜹니다(프로그램을 열어 둔 동안 1분 30초마다 확인).

### 위험 지점
- **나이스 안에서 고친 것은 프로그램이 알 수 없습니다.** 나이스용 복사 때 묻는 창과 "반영 완료" 단추가 그 빈틈을 메웁니다. 끝까지 안 누르면 담당자 화면에 남고 독촉 메시지로 챙깁니다.
- **"내 담당"을 안 정한 선생님에게는 요청이 보이지 않습니다.** 담당자 화면 분야별 표에서 담당교사가 "(미정)"인 줄을 보고 그 선생님께 정해 달라고 하세요.
- 분야·상세 분야 이름이 시트와 같아야 짝지어집니다. "사회"와 "주제(사회)"처럼 서로 포함되면 같은 것으로 봅니다.
- 학번은 5자리(30205 = 3학년 2반 5번)로 읽습니다. 학번이 빈 "전체" 줄은 담임 단계 없이 담당자가 바로 확인합니다.
- 점검 줄에는 학생 이름과 오류 내용이 들어갑니다. 웹앱 주소·암호는 교직원에게만, 점검이 끝나면 **끝난 줄 시트에서 지우기**를 하세요.

## 12. 명단 자동 정리 · 내 암호 잠금 · 새 학년도

### 명단 자동 정리
- 엑셀 파일을 올리거나 표를 통째로 붙여넣으면 제목 줄(학년·반·번호·이름, 학번·이름, 반·번호·이름, 번호·이름)을 찾아 정리합니다. 성별·생년월일 같은 다른 칸은 무시하고, 시트가 여러 개면 명단이 가장 많은 시트를 고릅니다.
- 학번은 5자리(10215 = 1학년 2반 15번)와 4자리(1203 = 1학년 2반 3번)를 읽습니다.
- 학년이나 반 칸이 없으면 한 번 물어봅니다("1-2"처럼 답하면 됩니다).
- **위험 지점**: 제목 줄이 없으면 숫자와 이름을 추정합니다. 이때는 알림에 "추정했으니 확인해 주세요"가 뜨니 학급별 명단을 한 번 보세요.

### 내 암호로 잠그기
- 설정·백업 → 🔒 내 암호로 잠그기에서 각 선생님이 **각자** 암호를 정합니다. 그다음부터 프로그램을 열 때 암호를 묻습니다.
- 저장된 자료 자체를 암호로 바꿔(AES-256) 저장하므로, 같은 컴퓨터를 쓰는 다른 사람도 열 수 없습니다. 맨 위 🔒 단추로 바로 잠글 수 있고, 손대지 않으면 자동으로 잠깁니다(기본 30분).
- **위험 지점**: 암호를 잊으면 누구도 되찾을 수 없습니다. 엑셀 백업 파일은 잠기지 않습니다.

### 새 학년도 준비
- 설정·백업 → 🗓 새 학년도 준비 → **엑셀 백업 받고 초기화**: 엑셀 백업을 먼저 내려받고, 학생 명단·생기부 내용(그리고 고른 일정·시수·수정 요청 기록)을 지운 뒤 학년도를 1 올립니다.
- 남는 것: 영역·한도·입력 대상(%), 교정 규칙·금지어, 교사 이름·담당자 시트 연결, 잠금 암호.
- 담당자 시트는 새 학년도에 새로 만드는 것이 깔끔합니다(7번 순서 그대로).

## 13. 이 프로그램을 쓰지 않는 선생님

- 예전처럼 점검 시트에서 자기 분야 줄을 찾아, 고친 뒤 **담당교사 반영 날짜** 칸에 날짜를 적으면 됩니다. 담임도 **담임 반영 확인** 칸에 날짜를 적으면 됩니다.
- 시트에 적은 날짜는 프로그램을 쓰는 담임·담당자 화면에 그대로 반영되고 알림도 갑니다.
- 다만 이 선생님은 "내 담당"을 정하지 않았으므로, 담당자 화면에서 그 분야 담당교사가 "(미정)"으로 보입니다. 독촉 메시지에는 "(분야 담당 선생님)"으로 나옵니다.

## 14. 학교에 나눠 주기 (사이트 · 학교 전용 링크 · 입력 양식)

### 핵심 흐름
복붙(AI 결과) → 입력(자동 정리) → 엑셀로 변환(백업·양식) → 나이스 입력(나이스용 복사) → 확인(1·2·3차 점검) → 수정 → 소통(수정 요청·수정 완료) → 피드백(확인·재요청) → 수정

### 학교 전용 링크
- 담당자: 설정·백업 → 담당자 시트 연결에 웹앱 주소·암호를 넣고 **학교 전용 링크 복사** → 업무메신저로 선생님들께 보냅니다.
- 선생님: 링크를 **크롬·엣지에서** 열면 자동으로 연결되고, 이름 칸에 이름만 적으면 끝입니다(주소창에서 암호 부분은 바로 지워짐).
- **테스트 → 진짜 시트**: 진짜 시트를 만든 뒤 새 링크를 다시 보내면, 선생님들이 그 링크로 열 때 새 시트로 넘어가고 테스트 시트에서 받은 요청 기록은 자동으로 비워집니다. 이름·생기부 내용은 그대로입니다.
- **위험 지점**: 링크에 암호가 들어 있으니 교직원에게만 보내세요. 학기가 끝나면 시트 코드의 암호를 바꾸고 새 버전으로 배포한 뒤 새 링크를 보내면 예전 링크는 더 이상 쓸 수 없습니다.

### AI 결과 붙여넣기
- 붙여넣는 순간 `**굵게**`, `#` 제목, `- • 1.` 글머리표, 이모지, 코드 기호(`)를 자동으로 지우고 띄어쓰기·맞춤법을 정리합니다. 무엇을 고쳤는지 칸 아래에 나오고 되돌릴 수 있습니다.
- "~습니다" 같은 종결어미는 고치지 않고 경고만 띄웁니다(문장을 마음대로 바꾸지 않기 위해).

### 입력 양식 엑셀
- [생기부] 탭: 노란 칸에 학년·반·번호·이름, 연한 칸에 영역별 문장. "세특: 과목명"은 내 과목으로 고칩니다(사이트에 올리면 그 이름으로 바뀜).
- [바이트확인] 탭: 나이스 한도를 넘으면 빨간색. 엑셀 계산은 참고용, 최종은 사이트 기준입니다.
- [항목한도] 탭: 영역별 한도(파란 숫자). 고치면 사이트에도 그대로 들어갑니다.
- 사이트 → 설정·백업 → **엑셀 백업(또는 입력 양식) 불러오기**로 올립니다.

### 개인정보 지우기
- 담당자: 수정 요청 탭 ④ → **끝난(확인) 요청 시트에서 지우기 / 수정 요청 전부 지우기**.
- 선생님: 설정·백업 → 새 학년도 준비(백업 후 초기화) 또는 위험 구역 → 모든 자료 지우기. 명단에서 학생 하나만 지울 수도 있습니다.

## 15. 학생 특이사항 · 담임항목 · 탭 제목 알림

### 특이사항 (전입·전출·재택 등)
- 나이스 명단의 **비고** 칸(또는 "특이사항" 칸)을 읽어 자동으로 붙입니다. 전출 학생도 명단에 남고 표시만 됩니다.
- **입력 제외**: 전출 · 학업중단 · 유예·면제 → 카드가 흐리게 보이고, 30%·완료·빠진 입력 계산에서 빠집니다(필요하면 써도 됨).
- **사유 확인 안내**: 재택(순회)교육 · 위탁 · 장기결석 → 칸 아래에 "사유를 입력했는지 확인" 안내가 뜹니다.
- **고치는 곳**: 학생별 입력 화면 맨 위 "특이사항" 고르기, 또는 설정·백업 → 명단 보기에서 이름 누르기.
- 엑셀 백업 [생기부] 탭 이름 옆 "특이사항" 칸에 들어가고, 불러오면 그대로 되살아납니다.
- 코드에서 고칠 곳: `NOTE_LIST`(고를 수 있는 목록), `isOut`(입력 제외 기준), `noteWarn`(사유 안내 기준).

### 담임항목 (자율·진로·기타인적학적)
- 점검 시트 분야가 "담임항목"인 줄은 담당교사가 아니라 **그 학생 반 담임**에게 "고칠 것"으로 갑니다(담임 학급을 정해 두어야 함).
- 담임이 고친 뒤에는 담임 확인 단계를 건너뛰고 바로 **생기부 담당자 확인** 차례로 갑니다.

### 탭 제목 알림
- 브라우저 탭 제목에 "(3) 🛠 도디쌤 생기부 도우미"처럼 할 일 수가 늘 보입니다.
- 다른 탭을 보고 있을 때 새 요청이나 반영 완료가 오면 탭 제목이 "🔔 새 수정 요청 1건"으로 깜박입니다. 그 탭을 누르면 멈춥니다.
- 알림(팝업)은 프로그램을 열어 둔 동안만 옵니다. 닫혀 있으면 다음에 열 때 한꺼번에 보여 줍니다.

## 16. 수정 기록 (분란 방지용 증빙)

- **언제 남나**: 반영 완료, 담임 확인, 담당자 확인, 재요청, 요청 보냄을 누를 때마다 기록이 하나씩 쌓입니다.
- **무엇이 남나**: 일시, 처리 교사, 학생, 분야·상세, 요청 내용 → 변경 후, **고치기 전 → 고친 후 문장**(이 프로그램 칸 기준), **나이스 저장 확인(교사 체크)**과 시각, 메모.
  - "고치기 전"은 요청이 처음 왔을 때 칸의 글, "고친 후"는 반영 완료를 누를 때 칸의 글입니다.
- **나이스 저장 확인**: 반영 완료를 누를 때 "나이스에서 [저장]까지 하셨습니까?"를 반드시 묻고, 확인한 경우에만 기록·시트 날짜가 들어갑니다. 담임 확인도 "나이스에서 반영된 것을 보셨습니까?"를 묻습니다.
- **보는 곳**: 수정 요청 탭 📒 내 수정 기록, 학생별 입력 화면(그 학생 기록), **수정 기록 엑셀로 내려받기**, 엑셀 백업의 [수정기록] 탭.
- **위험 지점**:
  - 프로그램은 나이스 화면을 읽을 수 없습니다. "나이스 저장 확인"은 **선생님 본인이 확인했다고 체크한 기록**입니다(서명과 같은 성격).
  - 기록은 **각자 컴퓨터**에 남습니다. 엑셀 백업을 받아 두어야 컴퓨터를 바꿔도 남습니다. 점검 시트에는 날짜만 남습니다.
  - 나이스에서 고칠 때 이 프로그램 칸을 거치지 않고 나이스에서 바로 고치면 "고친 후" 문장이 실제와 다를 수 있습니다. 칸에서 고친 뒤 나이스용 복사로 붙여넣는 습관이 가장 정확합니다.

## 17. 동아리 명단 (여러 반에 걸친 그룹)

- 부원 명단은 **붙여넣기, 엑셀, PDF** 모두 됩니다. 학번(또는 학년·반·번호)과 이름이 있어야 동명이인이 섞이지 않습니다.

- **설정·백업 → 🎲 동아리·그룹 명단**: 동아리 이름과 영역(보통 동아리활동)을 고르고, 학번·이름 명단을 붙여넣거나 엑셀을 올리면 그룹이 만들어집니다.
- **영역별 입력**에 🎲 단추가 생기고, 누르면 그 동아리 부원만 모아서 씁니다. 다 쓰면 ✔완료로 바뀝니다.
- 명단에 없던 학생은 새로 추가됩니다. 점검·현황에 그룹별 입력 수가 나오고, 빠진 부원도 보여 줍니다.
- 엑셀 백업에 **동아리명단** 시트로 들어갑니다. 새 학년도 초기화 때 함께 지워집니다.
- **2026 바뀐 점**: 중학교는 창체 영역별 **이수시간을 생기부에 적지 않습니다**(기재요령 중 p.73·75). 학교스포츠클럽 활동시간도 삭제되었습니다(중 p.74). 그래서 동아리 시수 점검 기능은 만들지 않았습니다.

## 21. 맞춤법 보강 · 수정 요청 탭 정리 · 설명 접기 (11/12 오후)

**맞춤법·띄어쓰기 자동 교정 보강** (틀린 것이 분명한 것만 고칩니다)
- 안/않: 않되요 → 안 돼요, 안했다 → 안 했다, 않한다 → 안 한다
- 되/돼: 되요 → 돼요, 되서 → 돼서, 돼고 → 되고, 됬다 → 됐다
- 의존명사 띄어쓰기: 할수있다 → 할 수 있다, 배운것 → 배운 것, 발표할때 → 발표할 때, 할줄알고 → 할 줄 알고, 할거야 → 할 거야
- 보조용언 띄어쓰기: 하지않고 → 하지 않고, 하고있다 → 하고 있다, 되게되었다 → 되게 되었다, 돕기도했다 → 돕기도 했다
- 그 밖: 를통해/를바탕으로/및, 익숙치 → 익숙지, 이예요 → 이에요, 있슴 → 있음, 어짜피 → 어차피 등
- **안 바꾸는 것**(시험 통과): 편안하다, 불안해, 안하무인, 되도록, 이외에도, 공부할수록, 그것, 별것, 기도했다, 있습니다, 안녕
- 규칙에 없는 것은 카드의 **[네이버 맞춤법]** 단추로 한 번 더 검사합니다.
- 고친 버그: 앞뒤 조건이 붙은 규칙(예: "하고있다", "익숙치 않은")이 적용되지 않던 문제

**수정 요청 탭을 할 일별 작은 탭으로**
- 🛠 내가 고칠 것 · 📨 요청 보내기 · 👀 우리 반 확인(담임만) · 📤 보낸 요청(보낸 게 있을 때) · ⚙ 내 담당 · 🏁 담당자(담당자 모드)

**설명 접기**
- 탭 아래 한 줄 설명은 **[접기 ▲]**로 접고, **[❓ 이 탭은 무엇을 하나요?]**로 다시 폅니다. 접은 상태는 기억됩니다.

## 26. 되/돼 구별 보강 (11/14)

- 돼 = 되어. 말이 '되'로 끝나면 '돼': 그러면 안되. → 안 돼. / 해도 되. → 해도 돼. / 해야되 → 해야 돼
- 되야 → 돼야, 되도 → 돼도(되도록·되돌아는 그대로), 되버렸다 → 돼 버렸다, 돼었다 → 되었다, 됀다 → 된다
- 뒤에 말이 이어지면 '되': 안돼는 → 안 되는, 안돼고 → 안 되고
- 해야/어야 띄어쓰기: 공부해야한다 → 공부해야 한다, 참여해야됨 → 참여해야 됨
- 시험 문장 77개 통과 (바뀌면 안 되는 말 포함)

## 32. 학교 디데이 vs 내 디데이 (2026-11-14)

**두 종류**

- **🏫 학교 일정**: 담당자가 보내면 모든 선생님 화면에 뜹니다. 시트 스크립트 속성 `sched`에 보관됩니다.

- 시트 코드에 `ADMIN_KEY`(담당자 암호)가 있습니다.

**자주 고칠 곳**
- 사이트: `schoolSchedHTML`, `pushSchoolSched`, `allScheds`
- 시트 코드: `sched_`, `saveSched_`

**위험 지점**
- 담당자 암호는 공개 저장소에 넣지 않습니다. 저장소 코드에는 `여기에담당자암호`만 있습니다.
- 암호를 바꾸려면 시트 코드의 `ADMIN_KEY`를 고친 뒤 **새 버전으로 배포**해야 합니다.

## 33. 국립국어원 자료로 맞춤법 보강 · 칭찬 문구 안 겹치게 (2026-11-14)

  - 예: 웃사람→윗사람, 웃층→위층, 핑게→핑계, 문귀→문구, 망서리→망설이, 마춰→맞춰, 씁슬→씁쓸, 심부름군→심부름꾼.

- 낱말 규칙은 낱말 첫머리에서만 고칩니다. 그래서 "그로인해" 같은 말 중간은 건드리지 않습니다.

**문장 부호 규칙**
- 부호 앞의 띄어쓰기를 없앱니다. ("함 ." → "함.")
- 한글 사이 마침표·쉼표 뒤에 한 칸을 띄웁니다. ("함.그리고" → "함. 그리고")
- 마침표 두 개는 하나로 줄입니다. ("음.." → "음.")
- 숫자(1,000 / 3.5)와 영어(A.I.)는 그대로 둡니다.

**칭찬 문구 안 겹치기**

**시험 파일**

- `t51`: 한 바퀴 503개가 모두 다른지
