## 1. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 프로그램 전체(화면·기능·도디쌤 이미지 포함). 이 파일 하나만 깃허브에 올리면 됩니다. |
| `현황판_AppsScript.gs` | 담당자 구글 시트에 붙이는 코드. 입력 현황(숫자)을 받고, 수정 요청(점검→수정→확인)을 주고받습니다. |
| `설명서.md` | 이 문서 |

`index.html` 안의 코드는 번호가 붙은 12개 구역으로 나뉩니다.

| 구역 | 내용 |
|---|---|
| 1 | 계산 함수: 바이트 계산, 자동 교정, 기재요령 점검, 날짜 읽기, 수업일수 계산 |
| 2 | 데이터 구조와 저장(브라우저 저장소) |
| 3 | 공통 도구(복사, 파일 읽기, 알림 문구) |
| 4 | 입력 카드(글 쓰는 칸 하나) |
| 4 | (같은 구역) 네이버 맞춤법 검사기 연결: 글을 300자 이하 조각으로 나눠 복사 → 네이버 창 열기 → 교정본 붙여넣어 적용 |
| 10-2 | 수정 요청(생기부 메신저): 받기·보내기·수정 완료·확인·재요청·담당자 현황·알림 |
| 5~10 | 화면 7개(수정 요청 탭 포함): 영역별 입력 / 학생별 입력 / 점검·현황 / 일정(디데이·달력) / 시수 / 설정·백업 |
| 11 | 버튼·입력 처리 |
| 12 | 시작 |

## 2. 데이터 흐름

```
[교사 PC 브라우저]
  학생 명단·생기부 내용·일정·시수
        │  (저장: 이 PC 브라우저 안에만)
        ├──▶ 엑셀 백업 파일(.xlsx)  ← 다른 PC로 옮길 때도 이 파일
        ├──▶ 클립보드 복사 ──▶ 나이스 입력칸에 Ctrl+V
        └──▶ 숫자만 전송 ──▶ [담당자 구글 시트 "현황" 탭]
              (교사 이름, 학급, 항목, 학생 수, 작성·완료·초과 수)
```

- 학생 이름과 생기부 문장은 인터넷으로 나가지 않습니다.
- 구글 시트로 가는 것은 숫자와 교사 이름뿐입니다.
- 학생용 화면은 없습니다. 교사 혼자 쓰는 도구입니다.

## 3. 자주 고칠 곳

| 하고 싶은 일 | 방법 |
|---|---|
| 항목 추가·한도 변경 | 프로그램의 **설정·백업 → 기재요령 규칙** 표에서 고칩니다(코드 수정 불필요). |
| 내년 기재요령 반영 | 같은 화면에서 한도를 고친 뒤 **규칙 파일 내보내기** → 다른 선생님은 **규칙 파일 등록**. |
| 맞춤법 규칙 추가 | **설정·백업 → 내 교정 규칙**. 기본 규칙을 고치려면 코드에서 `SPELL_RULES` 를 찾습니다. |
| 경고 문구·금지 표현 | **내 금지어**에 추가. 기본 점검을 고치려면 코드에서 `LINT_RULES` 를 찾습니다. |
| 세특 입력 대상 30% 등 비율 | 프로그램 **설정·백업 → 기재요령 규칙** 표의 "입력 대상(%)" 칸. 코드에서는 `ratioOf` |
| 처음 뜨는 기본 항목 | 코드에서 `DEFAULT_ITEMS` 를 찾습니다. |
| 네이버 조각 크기(300자) | 코드에서 `NV_MAX` 를 찾습니다. |
| 색·글자 크기 | 코드 맨 위 `<style>` 안 `:root{...}` 줄. |

## 4. 개인정보·오류 위험 지점

1. **공용 PC**: 내용이 그 PC 브라우저에 남습니다. 공용 PC에서 썼다면 백업 후 **설정·백업 → 모든 자료 지우기**를 누르세요.
2. **백업 파일**: 엑셀·json 백업에는 학생 이름과 내용이 그대로 들어 있습니다. 업무용 PC나 교육청 드라이브에만 두고, 카카오톡·개인 메일로 보내지 마세요.
3. **브라우저 기록 삭제**: 인터넷 사용 기록(사이트 데이터)을 지우면 내용도 지워집니다. 화면 오른쪽 위 "백업 n일 전" 표시를 보고 자주 백업하세요.
4. **브라우저·PC마다 따로 저장**: 크롬에서 쓴 내용은 엣지나 다른 PC에서 보이지 않습니다. 엑셀 백업으로 옮깁니다. 카카오톡에서 링크를 눌러 열면 카톡 속 브라우저에 따로 저장되니, 실제 작성은 크롬이나 엣지에서 하세요.
5. **바이트 한도**: 기본값은 2026학년도 기준 추정값입니다. 기재요령의 "영역별 입력 가능 최대 글자수" 표와 실제 나이스 화면으로 반드시 대조하세요. 2026년에 줄어든 한도(진로 500자, 행특 300자)가 나이스에 반영됐는지도 확인이 필요합니다.
6. **엔터 바이트**: 기재요령은 1바이트로 적고, 현장 계산기들은 2바이트로 셉니다. 기본은 안전한 2바이트이고, 복사할 때 줄바꿈을 띄어쓰기로 바꾸므로 실제로는 문제가 되지 않습니다.
7. **자동 교정의 한계**: 맞춤법은 "틀린 형태가 분명한 표현" 약 70가지와 공백·기호만 고칩니다. 문맥을 봐야 하는 맞춤법(로서/로써, 든지/던지 등)은 잡지 못합니다. 고친 내용은 칸 아래에 표시되고 되돌릴 수 있습니다.
8. **기재요령 경고**: 대학명·교외 수상·어학시험·부모 직업·영문·특수문자 등을 낱말로 찾는 방식이라, 문제없는 문장에도 경고가 뜰 수 있고 못 잡는 경우도 있습니다. 최종 판단은 교사가 합니다.
9. **현황판 주소·암호**: 주소와 암호를 아는 사람은 누구나 숫자를 보낼 수 있습니다. 교직원 외에는 알리지 마세요.
11. **네이버 맞춤법 검사**: 이 기능을 쓰면 그 글이 네이버로 넘어갑니다(선생님이 직접 붙여넣는 방식). 글에 학생 이름이 들어 있으면 지우고 검사하세요. 네이버는 한 번에 300자까지만 검사하므로 프로그램이 문장 단위로 나눠 줍니다. 네이버 검사기는 특수문자를 지울 수 있으니 적용 뒤 한 번 읽어 보세요.
10. **시수 파일**: PDF·엑셀을 읽습니다. "날짜와 내용이 한 줄에 있는 표"나 "3월 아래 2(월) 입학식" 꼴만 읽고, 달력 모양 표·스캔한 그림 PDF·한글(hwp)은 읽지 못합니다. PDF는 표 칸이 여러 줄로 나뉘면 내용이 잘리거나 날짜가 빠질 수 있습니다. 읽은 결과는 반영 전에 표로 보여 주므로 분류와 빠진 날짜를 꼭 확인하세요.

## 5. 깃허브에 올리기 (처음 하는 분 기준)

1. 크롬에서 `github.com` 에 로그인합니다.
2. 오른쪽 위 **+** 를 누르고 **New repository**(새 저장소)를 누릅니다.
3. **Repository name**(저장소 이름)에 `saenggibu` 라고 적습니다.
4. **Public**(공개)을 고릅니다. 프로그램 코드만 공개되고, 학생 자료는 올라가지 않습니다.
5. 맨 아래 초록색 **Create repository**(저장소 만들기)를 누릅니다.
6. 다음 화면에서 **uploading an existing file**(기존 파일 올리기) 글자를 누릅니다.
7. `index.html` 파일을 화면에 끌어다 놓습니다.
8. 아래 초록색 **Commit changes**(변경 사항 저장)를 누릅니다.
9. 위쪽 메뉴에서 **Settings**(설정) → 왼쪽 **Pages**(페이지)를 누릅니다.
10. **Branch**(가지)에서 `main` 을 고르고 **Save**(저장)를 누릅니다.
11. 1~2분 뒤 `https://gtk0624-a11y.github.io/saenggibu/` 로 들어가면 열립니다.

수정할 때는 저장소에서 `index.html` 을 누르고 → 연필 모양 → 새 내용을 붙여넣고 → **Commit changes** 를 누릅니다. 써 둔 생기부 내용은 지워지지 않습니다.

## 6. 처음 쓰는 순서

1. **명단 넣기**: 처음 화면에서 **명단 엑셀 파일 올리기**. 학년·반·번호·이름(또는 학번·이름) 칸만 있으면 칸 순서·다른 칸·여러 반 섞임과 상관없이 알아서 정리합니다.
2. **설정·백업 → 기재요령 규칙**: 항목과 한도를 확인합니다. 필요 없는 항목은 지우고, 다른 과목 세특은 **항목 추가**.
3. **영역별 입력**: 위쪽 큰 단추로 학급과 영역을 고르고 학생별로 씁니다. 칸을 벗어나면 자동 교정됩니다.
4. **나이스용 복사** → 나이스 입력칸에서 Ctrl+V. 복사한 칸에는 "복사함" 표시가 붙습니다.
5. 끝나면 **설정·백업 → 엑셀로 백업 받기**.

이미 엑셀에 써 둔 내용이 있으면: 첫 줄을 `학년 | 반 | 번호 | 이름 | 항목 이름…` 으로 맞추고 **엑셀 백업 불러오기**로 한 번에 넣을 수 있습니다.

## 7. 담당자 시트 만들기 (구글 시트 — 입력 현황 + 수정 요청)

담당자(교무·생기부 담당)가 한 번만 만들면 됩니다. 이 시트 하나로 **입력 현황**과 **수정 요청(생기부 메신저)**이 모두 돌아갑니다.

1. 학교 구글 계정으로 새 **구글 스프레드시트**를 만듭니다. 이름은 `2026 생기부 점검` 정도로 합니다.
2. 위 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
3. 처음 보이는 코드를 모두 지우고, `현황판_AppsScript.gs` 내용을 전부 붙여넣습니다.
4. 맨 위 `var KEY = '여기에암호';` 에서 `여기에암호` 를 원하는 암호로 바꿉니다.
5. 디스크 모양(저장)을 누릅니다.
6. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행**을 누릅니다. 시트에 `수정요청` 탭과 `현황` 탭이 생깁니다.
7. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
8. 톱니바퀴를 눌러 **웹 앱**을 고릅니다.
9. **다음 사용자 인증 정보로 실행**: `나`, **액세스 권한이 있는 사용자**: `모든 사용자` 로 고릅니다.
10. **배포**를 누릅니다. 권한 확인 창이 뜨면 본인 계정 선택 → **고급** → **(안전하지 않음)으로 이동** → **허용** 순서로 누릅니다. 본인이 만든 코드라서 뜨는 창입니다.
11. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
12. 모든 선생님께 **프로그램 주소 · 웹 앱 URL · 암호** 세 가지를 알립니다.
13. 각 선생님은 생기부 도우미 **설정·백업 → 담당자 시트 연결**에 교사 이름(띄어쓰기 없이 정확히), 웹앱 주소, 암호를 넣고 **연결 시험**을 누릅니다.
14. 담당자는 같은 칸에서 **담당자 모드**를 켭니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (예전 현황판 코드를 쓰고 있었다면 이번 코드로 바꾸고 새 버전으로 배포해야 수정 요청이 됩니다.)

## 8. 독서기록 받기 (학생이 구글 폼으로 입력)

손글씨 사진을 읽는 대신, 학생이 책 제목과 지은이를 직접 입력하게 하고 그 결과를 프로그램에 불러옵니다.

### 폼 만들기 (한 번만)

1. 크롬에서 `forms.google.com` 에 들어가 **+ 새 양식**(빈 양식)을 누릅니다.
2. 제목을 `독서기록` 으로 적습니다.
3. 질문을 아래 6개로 만듭니다. **질문 이름은 그대로** 적어야 프로그램이 알아봅니다.

| 질문 이름 | 유형 | 설정 |
|---|---|---|
| 학년 | 객관식 | 보기: 1, 2, 3 |
| 반 | 객관식 | 보기: 1, 2, 3 |
| 번호 | 단답형 | 점 3개 → 응답 확인 → 숫자 → 정수 |
| 이름 | 단답형 | |
| 책 제목 | 단답형 | |
| 지은이 | 단답형 | |

4. 질문마다 오른쪽 아래 **필수**를 켭니다.
5. 오른쪽 위 **게시**(또는 보내기) → 링크 모양 → **URL 단축** → 복사해서 학생들에게 알려 줍니다. QR로 띄워도 됩니다.
6. 학생은 **책 한 권마다 한 번씩** 제출합니다.

### 프로그램에 넣기

1. 폼 화면 위쪽 **응답** 탭 → **Sheets에 연결**(초록색 표 모양)을 누릅니다.
2. 열린 구글 시트에서 **파일 → 다운로드 → Microsoft Excel(.xlsx)** 을 누릅니다.
3. 생기부 도우미 **설정·백업 → 독서기록 불러오기**에서 그 파일을 올립니다.
4. 넣을 내용과 경고(명단에 없는 번호, 이름이 다른 학생)를 확인하고 **이대로 넣기**를 누릅니다.
5. **영역별 입력** 탭에서 항목을 **독서활동상황**으로 바꾸면 학생별로 `책 제목(지은이), 책 제목(지은이)` 꼴로 들어가 있습니다.

같은 파일을 다시 올려도 이미 들어간 책은 다시 들어가지 않습니다. 학기 중에 여러 번 받아도 됩니다.

### 위험 지점

- 학생이 번호를 잘못 적으면 다른 학생에게 들어갑니다. 이름이 명단과 다르면 경고가 뜨니 그때 확인하세요.
- 책 제목·지은이 오타는 그대로 들어갑니다. 넣은 뒤 작성 탭에서 한 번 훑어보세요.
- 구글 폼 응답(학생 이름·읽은 책)은 선생님 구글 드라이브에 저장됩니다. 학교 구글 계정으로 만드는 것이 안전합니다.
- 독서활동상황의 기재 형식과 한도(기본값 1,500B로 넣어 둠)는 2026 기재요령 독서활동상황 쪽에서 확인하고, 다르면 설정에서 고치세요.

## 9. 완료 표시와 빠진 입력

- **완료 기준**: 영역마다 "입력 대상(%)"이 있습니다. 전원 쓰는 영역은 100%, 세특은 30%가 기본입니다. 학급에서 그 비율만큼 쓰면 영역 단추와 현황표에 **✔완료**가 붙습니다.
- **30% 넘음 알림**: 세특에서 목표 인원을 채우는 순간 "완료", 그보다 더 쓰면 "30%를 넘었습니다"가 화면 아래에 뜹니다. 위쪽 상자에는 학급과 학년 전체 비율이 같이 나옵니다.
- **빠진 입력**: 점검·현황 탭 **빠진 입력**에 학급·영역별로 아직 안 쓴 학생이 나옵니다. 이름을 누르면 그 학급·영역의 미작성 학생만 모아 보여 줍니다. 학생별 입력 탭에서는 그 학생의 빠진 영역이 맨 위에 나옵니다.
- 내가 쓰지 않는 영역은 설정에서 "내 담당"을 끄면 빠진 입력 목록에 나오지 않습니다.
- **위험 지점**: 30%는 기본값일 뿐입니다. 실제 입력 대상 범위는 학교 학업성적관리위원회가 정하므로 학교 기준으로 고치세요. 비율 계산은 올림입니다(28명×30% = 8.4 → 9명).

## 10. 엑셀 백업에 들어가는 것

엑셀 백업 파일 하나에 선생님이 입력한 것이 전부 들어갑니다.

| 시트 | 내용 |
|---|---|
| 생기부 | 학생 × 영역 입력 내용 |
| 바이트 | 칸마다 바이트 |
| 완료여부 | 완료 체크 |
| 나이스복사 | 나이스용 복사를 누른 시각 |
| 항목한도 | 영역 이름·한도·입력 대상(%)·내 담당 |
| 일정 | 일정·메모·끝남 |
| 휴업일 / 시수표 / 동아리 | 시수 탭 자료 |
| 교정규칙·금지어 | 내가 만든 교정 규칙과 금지어 |
| 설정 | 교사 이름·학년도·엔터 바이트·현황판 주소와 암호 등 |
| _복원용 (숨김) | 위 전부를 되살리는 자료. 지우거나 고치지 마세요 |

- **불러오기**: _복원용 시트가 있으면 전부 되살리고, 그 위에 생기부·완료여부 시트 내용을 덮어씁니다. 그래서 엑셀에서 내용 칸을 고쳐도 반영됩니다. 다른 시트(일정·시수표 등)를 엑셀에서 고친 것은 반영되지 않으니 프로그램에서 고치세요.
- **위험 지점**: 이 파일에는 학생 이름·생기부 내용과 함께 현황판 암호도 들어 있습니다. 업무용 PC나 교육청 드라이브에만 보관하세요.

## 11. 수정 요청 — 생기부 메신저 (입력 → 점검 → 수정 → 확인)

### 흐름

```
[작성 교사]  생기부 입력 ──(입력 현황 자동 전송)──▶ [담당자 시트 · 현황 탭]
                                                        │ 누가 어느 학급·영역을 쓰는지
[담임·담당자] 1·2·3차 점검 → "수정 요청 보내기" ──▶ [담당자 시트 · 수정요청 탭]
                                                        │ 받는 교사 자동 지정
[작성 교사]  화면에 🛠 빨간 요청 + 팝업 알림 ◀──────────┘
             고친 뒤 "나이스용 복사" → "수정 완료 보낼까요?" [확인]
             (나이스에서 바로 고쳤으면 "수정 완료" 단추)
                        │
[담임·담당자] ✔ "김정환 선생님이 고쳤습니다" 팝업 → [확인] 끝 / [재요청] 다시 작성 교사에게
[담당자]     차수별·교사별 미처리 현황, "미처리 독촉 메시지 복사" → 업무메신저에 붙여넣기
```

### 작성 교사
- 요청이 오면 맨 위에 `🛠 받은 요청 n`이 깜박이고, 알림을 켜 두었으면 화면 구석에 팝업이 뜹니다.
- **수정 요청** 탭 ① 받은 수정 요청 → **고치러 가기**를 누르면 그 학생 칸이 열립니다. 칸 위에 요청 내용이 주황색으로 보입니다.
- 고친 뒤 **나이스용 복사**를 누르면 "수정 완료를 보낼까요?" 창이 뜹니다. 나이스에 붙여넣고 **확인**을 누르면 끝입니다.
- 나이스에서 바로 고쳤다면 **수정 완료** 단추만 누르면 됩니다.

### 담임·담당자 (점검자)
- **수정 요청** 탭 ② 수정 요청 보내기: 차수·학년·반·번호·영역·내용을 넣고 **보내기**를 누릅니다. 받는 교사는 학급·영역으로 자동으로 찾습니다.
- 여러 건은 엑셀 6칸(학년·반·번호·이름·영역·내용)을 복사해 **여러 건 한꺼번에 보내기**에 붙여넣습니다.
- 수정 완료가 오면 팝업이 뜨고 ③ 내가 보낸 요청에 **확인 / 재요청** 단추가 생깁니다.
- 담당자 시트 `수정요청` 탭에 직접 적어도 됩니다(받는 교사는 비워 두면 자동).

### 담당자
- 설정에서 **담당자 모드**를 켜면 ④에 차수별·교사별 요청, 미처리, 수정 완료, 확인 수가 나옵니다.
- **미처리 독촉 메시지 복사** → 업무메신저에 붙여넣으면 선생님별 미처리 목록이 그대로 갑니다.
- 시트 `수정요청` 탭에서 상태·시각·메모를 언제든 볼 수 있습니다.

### 데이터 흐름과 개인정보
- 수정 요청에는 학생 학년·반·번호·이름과 요청 내용이 들어가며, **담당자의 학교 구글 시트**에 저장됩니다(지금 메신저로 주고받는 것과 같은 수준).
- 학생 생기부 문장은 기본으로 시트에 가지 않습니다. 설정의 "수정 완료 때 고친 문장도 보내기"를 켠 경우에만 갑니다.
- 웹앱 주소와 암호를 아는 사람은 요청 목록을 볼 수 있습니다. 교직원 외에는 알리지 마세요. 학기가 끝나면 암호를 바꾸고 새 버전으로 배포하는 것이 좋습니다.

### 위험 지점
- **나이스 안에서 고친 것은 프로그램이 알 수 없습니다.** 나이스용 복사 때 묻는 창과 **수정 완료** 단추가 그 빈틈을 메우는 장치입니다. 끝까지 안 누르는 선생님은 담당자 화면에 미처리로 남으니 독촉 메시지로 챙기세요.
- **교사 이름이 정확히 같아야** 요청이 갑니다. 받는 교사를 못 찾은 요청은 담당자 화면에 "(받는 교사 미정)"으로 나오니, 시트 `받는 교사` 칸에 이름을 적어 주세요.
- 받는 교사 자동 지정은 그 선생님이 이 프로그램에서 **입력 현황을 한 번이라도 보낸 뒤**에 됩니다. 같은 학급·영역을 두 선생님이 쓰면 자동 지정하지 않습니다.
- 알림은 **프로그램을 열어 둔 동안** 1분 30초마다 확인해서 띄웁니다. 닫혀 있으면 다음에 열 때 몰아서 알려 줍니다.
- 보낸 것이 시트에 반영되지 않으면 3분 뒤 "⚠ 시트에 반영 안 됨 — 다시 보내기"가 뜹니다.
- 구글 무료 계정 웹앱은 동시에 많이 접속하면 잠깐 느려질 수 있습니다. 학교(교육청) 구글 계정으로 만드세요.
- 코드에서 고칠 곳: 확인 주기 `90000`(밀리초), 차수 보기 `['1','2','3','4','5']`, 영역 짝짓기 `matchItem`.

## 12. 명단 자동 정리 · 내 암호 잠금 · 새 학년도

### 명단 자동 정리
- 엑셀 파일을 올리거나 표를 통째로 붙여넣으면 제목 줄(학년·반·번호·이름, 학번·이름, 반·번호·이름, 번호·이름)을 찾아 정리합니다. 성별·생년월일 같은 다른 칸은 무시하고, 시트가 여러 개면 명단이 가장 많은 시트를 고릅니다.
- 학번은 5자리(10215 = 1학년 2반 15번)와 4자리(1203 = 1학년 2반 3번)를 읽습니다.
- 학년이나 반 칸이 없으면 한 번 물어봅니다("1-2"처럼 답하면 됩니다).
- **위험 지점**: 제목 줄이 없으면 숫자와 이름을 추정합니다. 이때는 알림에 "추정했으니 확인해 주세요"가 뜨니 학급별 명단을 한 번 보세요.

### 내 암호로 잠그기
- 설정·백업 → 🔒 내 암호로 잠그기에서 각 선생님이 **각자** 암호를 정합니다. 그다음부터 프로그램을 열 때 암호를 묻습니다.
- 저장된 자료 자체를 암호로 바꿔(AES-256) 저장하므로, 같은 컴퓨터를 쓰는 다른 사람도 열 수 없습니다. 맨 위 🔒 단추로 바로 잠글 수 있고, 손대지 않으면 자동으로 잠깁니다(기본 30분).
- **위험 지점**: 암호를 잊으면 누구도 되찾을 수 없습니다. 엑셀 백업 파일은 잠기지 않습니다.

### 새 학년도 준비
- 설정·백업 → 🗓 새 학년도 준비 → **엑셀 백업 받고 초기화**: 엑셀 백업을 먼저 내려받고, 학생 명단·생기부 내용(그리고 고른 일정·시수·수정 요청 기록)을 지운 뒤 학년도를 1 올립니다.
- 남는 것: 영역·한도·입력 대상(%), 교정 규칙·금지어, 교사 이름·담당자 시트 연결, 잠금 암호.
- 담당자 시트는 새 학년도에 새로 만드는 것이 깔끔합니다(7번 순서 그대로).

## 13. 이 프로그램을 쓰지 않는 선생님

- 담당자 시트를 그 선생님과 **편집 권한으로 공유**합니다.
- 그 선생님은 시트 `수정요청` 탭에서 `받는 교사`가 자기 이름인 줄을 보고(필터 사용), 나이스에서 고친 뒤 `상태` 칸을 **수정 완료**로 바꿉니다. 수정 완료 시각은 자동으로 찍힙니다.
- 그러면 요청한 담임·담당자의 프로그램에 "수정 완료" 알림이 그대로 뜹니다.
- **위험 지점**: 이 선생님들은 프로그램에서 입력 현황을 보내지 않으므로 받는 교사가 자동으로 정해지지 않습니다. 요청을 보낼 때 받는 교사 이름을 직접 적어 주세요. 또 시트에서는 다른 선생님 요청도 보이고 고칠 수 있으니, 학교 선생님들에게만 공유하세요.
