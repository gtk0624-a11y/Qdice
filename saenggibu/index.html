📖 도디쌤의 생기발랄 사용설명서

생기부를 쓰고 → 나이스에 붙이고 → 점검하고 → 고치고 → 확인하는 일을 한곳에서 합니다.
내가 쓴 생기부 문장은 이 컴퓨터에만 저장됩니다. 학교 점검 시트로는 수정 요청과 숫자(진행률)만 갑니다.

✨ 이번에 새로 생긴 것
  • 학생 명단 자동 — 학교 링크로 들어오면 우리 학교 학생 명단이 저절로 들어옵니다. 명단 넣을 필요 없어요.
  • 맞춤법이 더 똑똑해졌어요 — 국립국어원 「한글 맞춤법·표준어 규정 해설」과 「문장 부호 해설」을 반영했습니다. (웃사람→윗사람, 핑게→핑계, 문귀→문구 등 100여 개 + 문장 부호)
  • 두 칸 띄어쓰기 자동 정리 — 쓰는 순간 두 칸은 한 칸으로, 마침표 뒤에 붙여 쓰면 한 칸 띄워 줍니다.
  • 영역별 엑셀 받기 — 반 전체 내용을 엑셀로 받아 나이스에 한 번에 붙입니다.
  • 동아리는 동아리별로 — "동아리활동"을 고르면 반 대신 내 동아리가 나옵니다.
  • 디데이 두 칸 — 맨 위에 🏫 빨간 칸(담당자가 보낸 학교 일정)과 📌 노란 칸(내 일정)이 따로 보입니다.
  • 메신저용 문구 복사 — 수정 요청을 보내면 메신저에 붙일 쪽지가 자동으로 복사됩니다.
  • 밀린 요청 경고 — 받은 수정 요청을 2일 넘게 두면 빨간 경고 띠가 뜹니다.
  • 챗봇 자료 4종 — 기재요령(173쪽)·길라잡이(121쪽)·자체 점검표·2학기 점검표에서 근거와 쪽수를 찾아 줍니다.
  • 꿈송이·도디쌤 응원 — 한 영역을 다 쓰면 도디쌤이 칭찬 한마디(500여 가지, 겹치지 않게)를 건넵니다.
① 처음 3분 — 이것만 하면 됩니다
  1. 학교 링크로 열기 — 받은 링크를 복사해서 크롬 주소창에 붙여넣기. 메신저 안에서 바로 열면 안 됩니다. 열리면 즐겨찾기(★).
  2. 이름 적기 — 처음 화면(또는 [설정·백업] 맨 위)에 선생님 이름.
  3. 내 담당 정하기 — [수정 요청 → ⚙ 내 담당]
    • 담임: 담임 학급만 고르면 끝
    • 교과: 분야(교과세특) → 과목 → 맡은 반 체크 → [＋ 추가]
    • 동아리: 분야(동아리) → 동아리 이름 → [＋ 추가]
    이걸 정해야 수정 요청이 선생님께 정확히 옵니다.
  4. 알림 켜기(선택) — [수정 요청]의 [알림 켜기] → 크롬에서 "허용". 컴퓨터 화면 구석에도 알림이 뜹니다.

💡 학생 명단은 자동으로 들어옵니다. 안 보이면 [설정·백업 → 학교 명단 다시 받기].

② 생기부 쓰기 — [영역별 입력]
  1. ① 학급과 ② 영역(세특·자율·진로·행특…)을 고릅니다. 단추 색이 빨강 → 노랑 → 초록으로 바뀌며 진행 정도를 알려 줍니다.
  2. 학생 칸에 쓰거나 붙여넣습니다. (AI로 쓴 글도 그대로 붙여넣기 → **, # 같은 꾸밈 기호는 자동으로 지워짐)
  3. 맞춤법·띄어쓰기는 쓰는 동안 자동으로 고쳐집니다. 바뀐 곳은 칸 아래에 보이고, 마음에 안 들면 [되돌리기].
  4. 글자 수(바이트)가 칸마다 보입니다. 넘으면 빨갛게 표시됩니다.
  5. 문맥이 애매하면 [바른한글 검사] → 글이 복사되고 부산대 검사기가 열립니다. Ctrl+V → [검사하기].
  6. 다 쓰면 [완료] 체크. 영역이 다 끝나면 도디쌤이 칭찬해 줍니다 😊

💡 동아리활동: 영역에서 "동아리활동"을 고르면 반 대신 동아리 칸이 나옵니다. 처음 한 번 [＋ 내 동아리 명단 넣기]로 부원 명단(엑셀·PDF·붙여넣기)을 넣으세요.

③ 나이스에 한 번에 붙이기 — 📥 엑셀 받기
  1. 영역별 입력 화면의 [📥 이 반 ○○ 엑셀 받기] (내 반 전부는 [내 반 전부]).
  2. 엑셀의 "나이스에 붙일 내용"(C열)을 첫 학생부터 끝까지 드래그해 복사.
  3. 나이스 같은 반의 첫 학생 칸에 붙여넣기 → [저장].

💡 번호 순서가 나이스와 같은지 꼭 확인하세요. 한 명씩 붙일 때는 칸의 [나이스용 복사].

④ 점검하다 고칠 곳을 찾았을 때 — 📨 요청 보내기
  1. [수정 요청 → 📨 요청 보내기]
  2. 점검 차수 → 학년·반·번호 → 분야 → 상세 분야 (옆에 받는 선생님 이름이 보입니다)
  3. 오류 내용과 변경 후를 적고 [📨 요청 보내기].
  4. 보내는 순간 메신저용 쪽지가 자동으로 복사됩니다. 경기도 메신저 쪽지 창에 Ctrl+V 하면 끝.

💡 받는 사람이 "담당 미정"이면 그 선생님이 아직 내 담당을 안 정한 것입니다. 쪽지에 이름을 직접 넣어 주세요.

⑤ 나에게 수정 요청이 왔을 때 — 내가 고칠 것
  1. 꿈송이가 있는 노란 알림이 뜨고, [수정 요청] 탭에 빨간 숫자가 붙습니다.
  2. [ 내가 고칠 것] → [고치러 가기]로 그 학생 칸에 가서 고칩니다.
  3. 나이스에서 고치고 [저장]까지 합니다.
  4. [✔ 나이스에서 고쳤어요]를 누릅니다.

⚠ 이 사이트에서 고쳐도 나이스는 바뀌지 않습니다. 나이스에서 직접 고치고 저장해야 끝입니다. [나이스에서 고쳤어요]는 "고쳤다"고 알리는 단추입니다.

→ 시트의 "반영 기록" 칸에 누가·언제 고쳤는지가 남아, 다시 묻지 않아도 됩니다.
→ 받은 요청을 2일 넘게 두면 화면 위에 빨간 경고 띠가 뜹니다.

⑥ 담임 — 👀 우리 반 확인
  1. 우리 반 학생이 고쳐지면 알림이 옵니다.
  2. 나이스에서 고쳐진 것을 확인하고 [✔ 우리 반 확인했어요].
  3. 안 고쳐졌으면 [재요청]을 누르고 이유를 적습니다.
⑦ 디데이 · 일정
  • 🏫 빨간 칸 = 학교 일정: 생기부 담당자가 보낸 마감·점검 일정입니다. 모든 선생님 화면 맨 위에 똑같이 뜹니다. 3일 안으로 다가오면 꽉 찬 빨강으로 바뀝니다.
  • 📌 노란 칸 = 내 일정: [일정] 탭에서 내가 넣은 개인 마감입니다. 나만 보입니다.
  • 마감 3일 전부터 화면 위에 알림 띠가 뜹니다. 칸을 누르면 일정 탭으로 갑니다.
  • 점검 일정 PDF를 화면에 끌어다 놓으면 날짜를 찾아 내 일정에 넣어 줍니다.
⑧ 도디쌤 챗봇 — 기재요령 물어보기
  • 오른쪽 아래 [도디쌤에게 물어보기]. "개근 기준", "행특 글자 수", "AI로 써도 돼?"처럼 물어보세요.
  • 2026 기재요령(중학교)·기재 길라잡이·자체 점검표·2학기 점검표에서 찾아 근거 원문과 쪽수를 보여 줍니다. (기재요령은 책에 인쇄된 쪽 번호로)
  • 챗봇은 낱말로 찾아 주는 도우미입니다. 애매하면 생기부 담당자에게 문의하세요. 혼자 추측해서 입력하면 다시 고쳐야 합니다.
⑨ 생기부 담당자만 — 🔐 담당자 모드
  • [설정·백업]의 🔐 담당자 모드 칸에 담당자 암호를 넣고 [켜기]. 암호를 모르면 켜지지 않습니다.
  • 전체 진행 현황·선생님 연결 현황·📊 점검 시트 바로 열기
  • 🏫 학교 일정 보내기: [일정] 탭에서 일정을 넣고 [모든 선생님께 보내기] → 메신저용 안내문이 자동 복사됩니다.
  • 📋 메신저용 복사 (미처리 독촉): 안 고친 선생님별 목록을 쪽지로 만들어 줍니다.
  • 점검 차수 고치기: 모든 선생님 화면에 똑같이 적용됩니다.
  • 학생 명단 고치기(전학·전입): 점검 시트의 '명단' 탭을 고치면 됩니다.
⑩ 백업 · 다른 컴퓨터 · 잠금 · 새 학년
  • 엑셀 백업: [설정·백업 → 엑셀로 백업 받기]. 일주일에 한 번. ("● 저장됨" 옆에 "백업!"이 보이면 받을 때)
  • 다른 컴퓨터에서: 그 컴퓨터에서 학교 링크를 열고 → [엑셀 백업 불러오기].
  • 잠금: 공용 컴퓨터라면 [설정·백업 → 잠금 켜기]. 암호를 잊으면 풀 수 없으니 백업을 꼭 받아 두세요.
  • 새 학년: [설정·백업 → 엑셀 백업 받고 다음 학년도로 초기화].
⑪ 자주 묻는 질문
맞춤법 교정은 믿을 만한가요?
국립국어원 「한글 맞춤법·표준어 규정 해설」(2018)과 「문장 부호 해설」(2014)을 바탕으로 만들었습니다. 다른 뜻의 바른 낱말까지 바꾸지 않도록 하나하나 골라 넣었고, 바른 문장이 바뀌지 않는지 시험을 거쳤습니다. 다만 문맥을 알아야 하는 것(-로서/-로써 등)은 [바른한글 검사]로 한 번 더 확인하세요.
스페이스를 두 번 눌렀는데 한 칸이 됐어요.
정상입니다. 생기부에는 두 칸 띄어쓰기가 없어서 쓰는 순간 한 칸으로 정리합니다. 줄바꿈(엔터)은 그대로 둡니다.
팝업(알림)이 안 와요.
① 사이트 창이 열려 있나요? (닫지 말고 작게 내려 두세요) ② [알림 켜기]를 허용했나요? ③ 내 담당이 맞게 정해져 있나요? 알림은 1~2분 안에 옵니다.
경기도 메신저로 자동으로 알림이 가나요?
아니요. 교육청 메신저는 바깥 프로그램과 연결되지 않습니다. 대신 요청을 보내면 메신저용 쪽지가 자동으로 복사되니 메신저에 Ctrl+V만 하세요.
담당자가 내 생기부 문장을 볼 수 있나요?
아니요. 문장은 내 컴퓨터에만 있습니다. 담당자는 숫자(작성 수·초과 수)와 수정 요청만 봅니다.
학생 명단이 안 보여요 / 전학생이 있어요.
[설정·백업 → 학교 명단 다시 받기]. 전학·전입은 담당자가 점검 시트 '명단' 탭을 고치면 반영됩니다. 써 둔 글은 그대로 남습니다.
빨간 🏫 칸과 노란 📌 칸은 뭐가 달라요?
빨강은 담당자가 모두에게 보낸 학교 일정, 노랑은 내가 넣은 개인 일정입니다.
사이트를 안 쓰는 선생님은요?
지금처럼 점검 시트에 직접 날짜를 적으면 됩니다. 사이트 쓰는 사람에게도 똑같이 반영됩니다.
크롬을 바꿨더니 다 사라졌어요.
자료는 크롬마다 따로 저장됩니다. 원래 쓰던 크롬으로 열거나, 엑셀 백업을 불러오세요.
화면이 예전 그대로예요.
Ctrl+Shift+R로 새로 고치면 최신 화면이 나옵니다.
시수 탭이 없어요.
2026년부터 중학교 창체 이수시간은 적지 않아 숨겼습니다. 필요하면 [설정·백업 → 시수 탭 보이기].
