# 곡선 마을의 양심 (마피아) 구조 설명

## 1. 파일 구조
- index.html : 앱 전체(학생·교사·전광판 화면, 게임 엔진, 애니메이션). 한 파일입니다.
- teacher.html : 교사용 진입 주소. index.html?mode=teacher 로 넘겨 줍니다.
- board.html : 체육관 전광판용 진입 주소. index.html?mode=board 로 넘겨 줍니다.
- ggumsong.png : 꿈송이 이미지.

## 2. index.html 안의 구역 (위에서 아래 순서)
1. 설정: FIREBASE_CONFIG, TEACHER_PIN(0624), DEF_SEC(밤45·토론240·투표40·변론20·찬반20초)
2. ENGINE: 역할 배정, 소문 생성, 밤 결과, 판단·투표·찬반 집계, 승패, 점수
3. 백엔드 어댑터: Firebase 연결, 실패 시 체험 모드(이 기기 안에서만)
4. 공통 도구: 구독, 효과음, 타이머
5. 학생 화면: 접속, 역할 카드(꾹 누르기), 단계별 화면, 유령 화면
6. 교사 진행 로직: 시작 → 밤 → 새벽 → 토론 → 판단 → 투표 → 변론 → 찬반 → 처형 → 종료
7. 연출: 타자 효과, 룰렛, 새벽 발표, 개표, 정체 공개
8. 교사·전광판 화면, 점수표, CSV 내려받기

## 3. 데이터 흐름
- 저장 위치: rooms/{방코드}/mafia
- 교사 화면이 진행자입니다. 단계 전환과 집계는 교사 기기에서만 일어납니다.
- 학생은 자기 역할·자기 행동 칸과 공개 상태만 읽고 씁니다.
- 교사 → (공개 상태 기록) → 모든 학생·전광판 화면이 구독해서 표시합니다.
- 학생 → (밤 행동, 판단, 투표, 찬반) → 교사 화면이 마감 때 집계합니다.

## 4. 자주 고칠 곳
- 교사 PIN, 단계별 제한 시간: 파일 맨 위 설정 구역
- 역할 인원 비율: ENGINE의 rolePlan
- 점수 규칙: pointsJudge, pointsExec, pointsEnd
- 문구·소문 내용: genNotes 주변 문장 배열
- 연출 속도: 7번 연출 구역

## 5. 개인정보·오류 위험 지점
- 역할 비밀은 화면에서만 가려집니다. Firebase 규칙이 열려 있으면 개발자 도구로 볼 수 있습니다. 수업용으로는 충분하지만 시험·성적과 연결하지 마십시오.
- 학생은 번호·이름 정도만 입력하게 하십시오.
- 학년판(약 90명 동시)은 Firebase 요금제·동시 접속 한도를 확인하고, 체육관 와이파이로 사전 리허설을 하십시오.
- 교사 화면을 닫거나 절전되면 진행이 멈춥니다. 교사 기기는 절전을 꺼 두십시오.
- QR 생성은 외부 CDN(cdnjs)에 의존합니다. 접속 불가 시 방 코드 주소를 직접 안내하십시오.
- 체험 모드는 한 기기 안에서만 동작합니다(여러 기기 연동 안 됨).
