## 2. 한 판의 흐름 (개인 모드, 약 50분) — "내가 쓴 글이 결과를 바꾼다"

| 장면 | 형식 | 학생이 하는 일 |
|---|---|---|
| 장면 1 흉년의 봄 | 🏯 책사 회의 | 책사 3명 중 채택 **또는 ✍️ 제3의 길** → 한 줄 논증 → 재반박 → 탈락자 지명 |
| 장면 2 무너진 질서 | ⚔️ 맞대결 | 살아남은 두 책사의 토론(주장·공격)을 듣고 승자 판정 **또는 제3의 길** → 판정문 → 재반박 → 탈락자 지명 |
| 장면 3 최후통첩 | 🚨 긴급 결단 | 증거 1장, 짧은 제한 시간(보통 80초, 순한 맛 120초) → 결단 → 재반박 → **반전** |
| 마지막 | 판결문 | 재상 선택 → RAFTS 「재상 임명 교서」 (폐위되면 「회고록」) |

**글이 결과를 바꾸는 장치**
1. **한 줄 논증 판정 4가지**: ① 분량 ② 사상가 개념어 ③ 근거(왜냐하면·따라서…) ④ **상황·증거**(장면의 상황어나 연 증거의 내용).
   ④가 없으면 개념어를 써도 무조건 ⚠️흔들림 → "개념어 + 왜냐하면" 꼼수가 통하지 않습니다. ④가 있을 때 ①②③ 모두 = 🏆, 2개 = ✅, 그 이하 = ⚠️.
2. **📎 증거 인용 보너스**: 열어 본 증거 카드의 핵심 낱말을 글에 쓰면 그 카드의 보너스가 붙습니다.
3. **✍️ 제3의 길**: 어느 책사도 따르지 않고 직접 해결책을 씁니다. **서로 다른 사상가 2명의 개념어**가 있어야 하고 15자 더 길어야 합니다. 🏆이면 큰 효과와 특별한 이야기·씨앗, ⚠️이면 크게 손해. 제3의 길 🏆 2번이면 판결문 점수와 상관없이 숨겨진 엔딩 후보가 됩니다.
4. **🎯 약점 맞춤 반박**: 공손연이 학생 글에서 빠진 것을 골라 찌릅니다 — 상황 → 개념 → 근거 → 대가 → (다 갖추면) 반대 사상가의 비판. 재반박도 그 약점을 메워야 통과합니다.
5. **결과는 장면 끝에 공개**: 결단한 뒤 재반박하는 동안 게이지는 "64 → ❔"로 가려지고, 장면 끝에 결과 이야기와 함께 해결책·증거 보너스·재반박 효과가 한꺼번에 공개됩니다.
6. 장면 2부터 저절로 줄어드는 양, 지난 선택이 돌아오는 **씨앗**, **돌발 사건**, 떨어뜨린 책사에 따라 달라지는 **반전**은 그대로입니다.

**긴장감 장치 7가지 (쪼는 맛)**
| 장치 | 하는 일 | 고치는 곳 |
|---|---|---|
| 🏆 반 실시간 순위 | 결과·완료 화면과 📺 큰 화면에 순위(세 게이지 합 + 제3의 길 대성공 ×5, 폐위는 0). 🎛️ 진행 탭에서 반마다 끌 수 있음 | `app.js` `rankScore` |
| 👥 이름 있는 사람들 | 연이(아이)·허 노인·장수 맹렬이 내 결과에 따라 웃고, 떠나고, 배신하고, 죽음. 완료 화면에 "사람들의 운명" | `content.js` `npcs`, 장면마다 `sceneX.sN.people` |
| ⚔️ 패나라 진군 막대 | 장면마다 +15, 선택·판정에 따라 더 다가오거나 물러남(흔들림 +8, 시간 초과 +12). 100이 되면 침공(군사 -15, 민심 -10) 후 60으로 | `content.js` `march`, `sceneX.sN.march` |
| 🧓 공손연과의 공방 | 재반박이 **최대 3번**(순한 맛 2번). 공손연이 매번 다른 약점을 찌름. 다 막으면 감복(충성↑), 한 번이라도 밀리면 끝(충성↓). 충성이 -2 이하면 배신 반전, 4 이상이면 무릎 꿇는 반전 | `TENSION`의 `rally`, `app.js` `A.submitRebut` |
| 📯 급보! | 쓰는 도중(18초 뒤 또는 25자 쓴 뒤) 새 사건이 끼어듦. 글에 그 낱말을 반영하면 민심 +4, 무시하면 피해 | `sceneX.sN.alarms`, `TENSION`의 `alarm`(나올 확률) |
| 🎲 확신도 걸기 | 결단 뒤 도장 보기 전에 건다. 확신한다: 대성공 +12 / 흔들림 -12 | `app.js` `BET` |
| 💀 진짜 손실 | 손실 배수 상향, 민심 시작 55, 장면마다 줄어드는 양 증가 | `TENSION`의 `loss`, `decay` |

**📖 수업 자료와 힌트 사다리** (⚙️ 설정 → 📖 수업 자료에서 장면마다 편집)
- **수업 노트**: 선생님이 요약한 개념 정리(+ 학습지·판서 사진, 구글 드라이브 링크). 학생은 쓰는 화면에서 [📖 수업 노트]로 펼쳐 봄.
- **힌트 3단계**: 1단계(방향 질문) 공짜 → 2단계(개념 짚기) 민심 -2, 열쇠를 풀면 공짜 → 3단계(문장 틀) 힌트 카드 1장, 숨겨진 엔딩 불가. **3단계 틀을 그대로 베끼면 흔들림으로 판정**.
- **🔑 학습지 열쇠**: 수업 때 배운 낱말을 묻는 문제. 맞히면 힌트 카드 +1, 2단계 공짜. → 수업을 잘 들은 학생이 게임에서 유리해짐.

**📚 도감 = 사상가 정리 카드**: 내 기록 → 도감에서 만난 사상가를 누르면 명언·인간관·핵심 주장·주요 개념(뜻풀이)·비판이 정리되어 나옵니다. **⚙️ 설정 → ① 사상가·도감**에서 선생님이 교과서·수업에 맞게 고칠 수 있고, 고친 사상가는 "선생님이 고친 정리" 표시가 붙습니다.

자동 판정은 **게임 진행에만** 쓰고 성적에는 쓰지 않습니다.

## 3. 교사 진행 순서

> 🎛️ 진행 탭 맨 위 **📘 진행 순서 · 수업 흐름 한눈에 보기**를 펼치면 같은 내용이 짧게 나옵니다(`teacher.js`의 `guideH`에서 고침).
> 파일을 고쳐 올린 뒤에는 `index.html` 아래쪽 `?v=숫자`를 바꿔야 학생 기기가 옛 파일을 쓰지 않습니다.

1. **🎛️ 진행**: 반 만들기 → 단원 고르기 → 긴장감(순한·보통·매운 맛) → QR·코드 보여 주기 → [▶ 시작]
2. 수업을 프로젝터로 보여 줄 때는 **📺 큰 화면** 탭(방 코드·QR, 장면별 진행 인원, 반 선택 분포, 공개 후 반 전체 엔딩)을 띄웁니다.
3. 필요하면 **🚪 진도 잠금**으로 "장면 1까지만" 열어 반 전체 속도를 맞춥니다. [⏸ 일시정지]하면 제한 시간도 멈춥니다.
3. **📊 현황판**에서 진행 상황을 봅니다. 빨간 줄 = 민심 20 이하·폐위. [보기]로 한 학생의 모든 글을 봅니다.
4. 수업 후 **📝 판결문·점수** → [💾 전체 TXT] → 하이러닝에 올려 채점 → 점수 칸에 입력(학생에게 보일 한마디도 가능)
5. 다음 시간 **🎛️ 진행** → [📣 엔딩·점수 공개]
6. **🗂️ 포트폴리오**: 기준 4개(제출·분량·개념어·반론) 자동 확인 → 칸을 눌러 선생님 판단으로 바꿈 → CSV
7. **🔎 관찰 기록**: 세특 쓸 때 참고할 근거(경로·개념어·신념 변화). 문장은 선생님이 직접 씁니다.
8. **📈 시범 지표**: 완주율, 평균 시간, 개념어 사용률, 재반박 성공률, 평균 판결문 길이, 채택·탈락·엔딩 분포
9. **💬 피드백**: 학생·시범 운영 선생님이 오른쪽 아래 [💬 피드백]으로 보낸 의견이 모입니다.

## 4. 교사·학생 데이터 흐름

```
[학생 태블릿] 기기 저장 ─0.9~2.5초 뒤 자동 전송→ rooms/DS_방코드/students/s번호
              (게이지·선택·한 줄 논증·재반박·판결문·붙여넣기 기록·신념 지표·도감 전체)
              ← 실시간 수신 ─ rooms/DS_방코드/meta        (단원·상태·긴장감·진도 잠금·결과 공개)
              ← 실시간 수신 ─ rooms/DS_방코드/score/s번호  (판결문 점수·한마디·포트폴리오 판단)
              ← 필요할 때만 ─ rooms/DS_방코드/students     ([우리 반은?] 누를 때 반 분포)
[교사 화면]   rooms/DS_방코드 전체를 실시간 수신, meta·score만 씀
[공통]        rooms/DSCONTENT/default  (⚙️ 설정: 사상가 고친 값 th, 그림 img·thImg, 판정 judge, 긴장감 tn, 단원 off·reviewed, 배경 bg·bgImg, 성취기준 std,
                                          수업 자료 lesson/단원/장면, 학습지 사진 limg·limgOn)
              rooms/DSFEEDBACK         (💬 피드백)
```

학생 점수는 학생 기록과 **다른 곳(score)**에 저장되어, 학생 기기가 자동 저장을 해도 선생님이 넣은 점수를 덮어쓰지 않습니다.

## 6. 개인정보·오류 위험 지점

**개인정보**
- 기본값은 **번호만** 받습니다(이름 받기는 반마다 켤 수 있음). 시범 운영은 번호만 받으세요.
- 학생 글은 서버에 저장됩니다. 학기·시범이 끝나면 **⚙️ 설정 → ⑦ 학생 기록 → 모두 삭제**로 지우세요. 지우기 전에 CSV를 내려받아 두세요.
- Firebase 규칙이 `rooms` 아래를 열어 둔 구조입니다(국가 만들기와 동일). 방 코드를 아는 사람은 읽을 수 있으므로, 학생에게 **실명·실제 사연을 쓰지 말라**고 안내해 주세요(입장 화면에도 안내 문구가 있음).
- 다른 학교에서 시범 운영할 때도 같은 Firebase에 저장됩니다. 끝나면 그 반 기록을 지워 주세요.
- 교사 비밀번호 0624는 화면 잠금일 뿐, 진짜 보안이 아닙니다.

**오류·운영 위험**
- **붙여넣기 기록**: 학생이 다른 곳에서 글을 붙여 넣으면 횟수와 글자 수가 남습니다(현황판 빨간 숫자). 감시가 아니라 AI 부정행위 확인을 위한 관찰 근거입니다.
- **제한 시간**: 학생이 화면을 떠나 있어도 시간은 흐릅니다(일시정지 중에만 멈춤). 시간 안에 10자 미만이면 "결단하지 못했다"(민심 -15), 10자 이상이면 쓴 만큼 판정합니다.
- **같은 번호 두 기기**: 다른 기기에서 같은 번호로 들어오면 "이어서 할까요?"를 묻습니다. 번호를 잘못 넣은 학생이 다른 학생 기록을 이어받을 수 있으니, 이상하면 현황판에서 확인하세요.
- **단원 초기화**: 현황판 [단원 초기화]는 그 학생의 이번 단원만 지웁니다. [삭제]는 그 학생의 모든 기록을 지웁니다.
- **카카오톡 브라우저**: [파일로 저장]이 안 될 수 있습니다. 이때는 [복사]를 쓰세요.
- **학교 와이파이가 Firebase를 막으면** 하단에 "체험 모드"가 뜹니다. 수업 전에 태블릿 한 대로 먼저 확인하세요.
- **상황어 판정의 한계**: 상황어(곡식·창고·도적…)가 들어가기만 하면 ④를 통과합니다. 문맥까지 보지는 못합니다.
- **개념어 자동 판정의 한계**: 1글자 개념어(인·예·법·도)는 낱말로 따로 쓰였을 때만 인정하고, "예를 들어"처럼 다른 뜻은 빼도록 했지만 완벽하지 않습니다. 학생이 개념어만 나열해도 통과될 수 있으므로 **성적은 판결문 루브릭으로만** 매깁니다.
- **배경 그림 용량**: 배경은 가로 900px·약 120KB로 줄여 데이터베이스에 저장합니다. 장면마다 하나씩, 단원당 4장 정도면 괜찮지만 많이 올리면 첫 화면이 느려질 수 있습니다.
- **수업 자료는 방 코드를 아는 사람이 읽을 수 있습니다.** 교과서·문제집 본문을 그대로 넣지 말고 선생님이 요약한 내용만 넣으세요. 학습지 사진도 가로 900px로 줄여 저장합니다.
- **급보 판정의 한계**: 급보 낱말이 글에 들어가기만 하면 "대응"으로 인정합니다.
- **효과음**: 태블릿 30대에서 동시에 나면 시끄럽습니다. 기본은 꺼져 있습니다.
- **아직 확인하지 못한 것**: 30명 동시 접속, 실제 학교 태블릿 화면, 실제 Firebase 연결(시험은 체험 모드로만 했습니다).

## 7. Firebase 보안 규칙 공부용 초안 (직접 적용해 보실 때)

지금은 `rooms` 전체가 열려 있습니다. 공부 삼아 조이고 싶으시면 Firebase 콘솔 → Realtime Database → 규칙에서 아래처럼 시작해 보세요. **다른 게임(국가 만들기 등)도 `rooms`를 쓰므로**, 바꾼 뒤 그 게임들이 잘 되는지 꼭 확인하세요.

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true,
        "students": { "$sid": { ".validate": "newData.child('sid').val() === $sid || !newData.exists()" } }
      }
    }
  }
}
```
