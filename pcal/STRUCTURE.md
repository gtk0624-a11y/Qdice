# 업무파탈 캘린더 구조 설명서

© 김정환 · M.A.D.T (Moral And Digital Teacher) — 「업무파탈」의 한 조각 ① (캘린더)

## 1. 한눈에 보기
빌드 도구가 필요 없는 **HTML 한 장짜리 앱**입니다. `index.html` 하나만 깃허브 페이지(예: `Qdice/pcal/index.html`)에 올리면 돌아갑니다. 엑셀·PDF 읽기 도구와 도디쌤 로고가 모두 파일 안에 들어 있어 인터넷 없이도 읽습니다(글꼴 5종 중 4종만 인터넷 필요).

## 2. 파일 구조
```
pcal/
  index.html   앱 전체(디자인·화면·읽기 도구가 한 파일에 합쳐진 완성본)
  dodi.jpg     도디쌤 로고 원본(index.html 안에도 들어 있음)
  ggumsong.png 꿈송이 원본(카드뉴스용)
  STRUCTURE.md 이 문서
```
고쳐서 다시 합칠 때는 작업 폴더의 조각 파일을 씁니다(요청하시면 함께 드립니다).
```
style.css        모든 디자인(색·배치)           parser.js      공문·메신저 날짜 읽기(업무파탈 inbox 파서 그대로)
app.js           화면·버튼·테마·저장·내보내기   reader_base.js 엑셀·PDF·텍스트 읽기, 달력 모양 표 읽기
reader_hwp.js    한글(hwp·hwpx)·워드(docx) 읽기 template.html 뼈대 / build.py 로 한 파일로 합침
```

## 3. 데이터 흐름 (교사·학생)
- **교사 1인용 일정 도구**입니다. 학생이 접속하는 화면과 교사↔학생 연동은 없습니다. (학생 연동이 필요하면 별도 수업용 앱으로 분리)
- 모든 일정은 `S`(items·kinds·set)라는 하나의 상태에 있고, 바뀔 때마다 `save()`가 **이 기기 브라우저(localStorage 키 `tfcal.v1`)** 에 저장합니다. 서버·로그인·외부 전송이 없습니다.
- 흐름: 붙여넣기/파일 → `ibxParse`·`extractSchedule`(읽기) → 확인 창(체크·수정) → `S.items` 추가 → `render()`.
- 파일은 브라우저 안에서만 읽습니다(엑셀 `XLSX`, PDF `pdfjsLib`, 한글·워드는 자체 압축 해제).
- 일정 하나: `{id,title,date,end,time,kind,memo,done}`  (`end`는 기간 일정의 끝 날짜, `time`은 "14:30~16:00")

## 4. 자주 고칠 곳
| 하고 싶은 일 | 위치 |
|---|---|
| 색 테마 추가·수정 | app.js `THEMES` |
| 글꼴 추가 | app.js `FONTS` (구글 글꼴 이름을 `g`에) |
| 기본 일정 종류·색 | app.js `DEFKINDS` |
| 공휴일 표시(양력 고정일) | app.js `HOL` (설날·추석 등 음력은 없음 → 학사일정 파일로 넣으세요) |
| 공문 읽는 규칙(마감 단어 등) | parser.js `IBX`, `IBX_DROP` |
| 학사일정 읽는 규칙 | parser.js `extractSchedule` / 달력 모양 표는 reader_base.js `gridLines` |
| 소개 화면 글 | app.js `introDlg()` |
| 주소·저작권·워터마크 | app.js `guard()`, `wmCss()` ← **워터마크·저작권은 끄는 설정이 없습니다. 지우지 마세요** |

## 5. 개인정보·오류 위험 지점 (꼭 읽기)
1. **학생 이름·성적은 붙여넣지 마세요.** 이 기기에만 저장되지만, 화면을 공유하거나 백업 파일(.json)·내보내기 파일(.ics)을 보내면 그대로 나갑니다.
2. **브라우저 기록·사이트 데이터를 지우면 일정이 사라집니다.** 「내보내기 → 백업」을 가끔 받으세요. 폰과 PC는 **서로 동기화되지 않습니다**(백업 파일로 옮김).
3. 공문 읽기는 날짜 모양을 찾는 **규칙 방식이라 틀릴 수 있습니다.** 그래서 확인 창에서 체크한 것만 들어가며, 넣은 뒤 「되돌리기」가 있습니다. 연도가 없는 날짜는 오늘 기준·학년도(3월~다음해 2월)로 짐작합니다.
4. 그림으로 된 PDF·스캔본은 글자를 읽지 못합니다. 배포용(복사 제한) 한글 파일은 PDF로 저장해 올리세요.
5. PDF 읽기는 브라우저가 작업 스레드(blob)를 허용해야 합니다. 일부 인앱 브라우저에서 막히면 크롬·삼성 인터넷으로 여세요.
6. 글꼴 4종(고운돋움·주아·명조·손글씨)은 구글 글꼴을 인터넷에서 받습니다. 막히면 기본 글꼴로 보입니다.
7. 구글 캘린더로 내보내는 .ics 는 시간이 없는 일정은 종일 일정으로, 시간이 있는 일정은 해당 시각으로 들어갑니다.
